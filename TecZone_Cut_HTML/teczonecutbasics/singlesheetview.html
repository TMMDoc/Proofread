Single sheet view

To open a sheet in the single sheet view, double-click the sheet in the sheet overview.

① Part overview bar
② Tool guides
③ Design window
④ Mini toolbar
⑤ Only in the single sheet view: Tasks
⑥ View functions

Part overview bar

Displays all single parts in the sheet program.

Use the part overview bar to:

  • To display a part’s status, view errors, warnings, overproduction, or underproduction.

  • To show a part’s rounded dimensions, use the unit system specified in the HomeZone parameters.

  • To display detailed information, view the part’s tooltip.

  • To display cutting programs for a part in TruPunch and TruMatic, select the button. The button is shown only if cutting programs are available.

  • To design a part, use Update part.

  • To open a part in HomeZone, click the part name.

  • To focus on a part in the design window, double-click the part.

  • To import a part into TecZone Cut, use Import part into TecZone Cut.

  • To create a sheet layout for a part manually, use Creating a sheet layout for a part manually.

  • To find or arrange parts, search or sort the part overview bar.

  • To set up the working range for the part overview bar, use Set up working range.

Tool guides

Includes options for modifying a tool’s performance.

To close a tool guide, press Esc.

Design window

Shows the sheet selected in the sheet overview.

For TruPunch and TruMatic, select an overview of all single parts in different angular positions in the design window.

Mini toolbar

The mini toolbar contains frequently used options for the active tool. To open it, right-click in the design window.

Only in the single sheet view: Tasks

To show or hide the task window, select the Open tasks button in the View > Window > Tasks tab.

The Open tasks window appears at the upper right of the working area. It displays errors, warnings, and information for the current sheet, such as missing disposals or unprocessed elements. To move the window, drag it to another location in the working area. Its position is saved.

The associated points on the sheet are listed for each message. By clicking on an entry in the list, the relevant position on the sheet is brought into focus and highlighted in color. The zoom factor can be set using the slider. The setting is saved.

Further information can be displayed via the tooltip.

The maximum number of entries displayed per task can be limited via the system rules variable
TaskPanelMaxNumOfIssuesPerTypeToDisplay.
As the last entry per job, the number of additional points which exist is displayed.

  • For punching machines, punch laser machines and TruLaser Center 7030 (L26):

    • For a completely unprocessed part, the task window creates one entry for the complete part. It creates entries for unprocessed elements only if the part has at least one processing operation.

    • To update the window interactively, select the Check button in the Optimization > Optimize tab.

    • To update the window from the panel, select Update tool list at the top right.

  • For 2D laser machines (except TruLaser Center 7030 [L26]):

    • Some messages for the current sheet appear automatically. To display the remaining messages, update the window interactively with Update tool list at the top right of the panel.

    • After a Machine change between 2D laser machines, removed elements appear as messages in the Open tasks window and are highlighted in orange on the sheet.

    • All messages generated by the machine change can be removed using the Remove machine change warnings button at the top right of the panel. All other messages are retained. The button is only displayed if there are messages about the machine change.

View functions

Select view functions in the View menu and, for some functions, in the footer.

These functions are available for 2D laser machines except for TruLaser Center 7030 (L26):

View function Description

Selection preview

Selection points will be displayed. E. g., when placing a construction line, the nearest catch point is indicated with a circle.

All points

All single points (corners, circle centers etc.) are displayed in the view.

The setting is saved.

Geometry

Geometries are displayed.

The setting is saved.

Processings

The processings are displayed.

The setting is saved.

Positioning lines

Traverse paths of the tool head/cutting head between the individual processings are displayed.

The setting is saved.

Positioning lines are also displayed if the simulation is manually executed.

Problems

Problems (e.g. collisions) are highlighted.

Clamp dead strips

The clamp dead strip is marked with a red dashed line.

If no processing takes place in this section, the program is not dependent on the clamp positions. The clamps can be set freely by the operator.

Slats

The slats set in the machine data are displayed.

Have slats displayed in the cutting program.

LiftMaster

The suction cup layout of the LiftMaster is displayed.

Machine

The outline of the machine including the control panel is shown.

Mark special cases in the current view.

The following special cases can be marked:

  • Fixed contours

  • Fixed parts

  • Cut up scrap

  • Tilting contours

  • Tilting parts

  • Parts according to dimensions

Roundings

  • Missing roundings: Rounding problems caused by missing roundings are highlighted in the view.

  • Roundings too small: Rounding problems caused by roundings which are too small are marked in the view.

  • Off: Rounding problems are not shown.

Tool setup

Optimization level

These functions are available for punching machines and punch laser machines:

View function Description

Additional tool contours

Display additional tool contours (e.g. obstructions on dies, PU strippers).

The setting is saved.

Scrap

Scrap areas which are removed by means of a scrap removal are colored in the view.

The setting is saved.

This function is also available for TruLaser Center 7030 (L26).

Optimization level

Activate if the processing operations of the active level are to be displayed. All processing operations are displayed by default.

This function is also available for TruLaser Center 7030 (L26).

Active tool

Only the processings of the active tool are displayed normally. Processings of the other used tools are shown in gray.

Highlight unprocessed geometries

A message is displayed indicating how many elements are not processed.

Unprocessed contours are shown in magenta.

This function is also available for TruLaser Center 7030 (L26).

Highlight unremoved contours

A message is displayed indicating how many elements are not removed.

Unremoved contours are displayed in magenta.

This function is also available for TruLaser Center 7030 (L26).

Tool change

A list with all tool changes is displayed.

Tool setup

Optimization level

If the display Order information is activated in the menu View, the customer name and the subsequent workstation are displayed for each part.
