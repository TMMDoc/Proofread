2D Laser Machines

The following colors and symbols information is for 2D laser machines.

Colors and lines

In the default setting, colors and lines have the following meaning:

Processings
Color Line type or shape and explanation

Blue

Solid: Positioning paths between the contours (except in case of SprintLine).

Dashed: Positioning paths between the contours with SprintLine.

Cyan

Solid: Positioning paths between the parts (except in case of SprintLine).

Dashed: Positioning paths between the parts with SprintLine.

Solid: Processing type vaporizing (without cutting).

Dashed: Positioning paths between the contours, which occur at cutting distance (Pathfinder).

Yellow

Solid: Corner treatment Rounding or Looping (without active path correction).

Dashed: Corner treatment Rounding or Looping (with active path correction).

Circle: Collision during processing.

Green

Solid:

  • Laser processing (without active path correction)

  • TwinLine Processing

  • Approach flag in case of laser processing: pre-cut

  • Pre-cut in thick sheet

Dashed: Laser processing with active path correction

Circle: Rounding radius is smaller than specified in the rules.

Dark green

Solid: Edgeline Bevel: bevel cut

Purple

Solid:

  • Contour part (no common cut).

  • Approach flag in case of laser processing: reduced approach speed

  • Laser crosses (prerequisite: the machine supports FLIN).

    • The sheet cut hits a finished part contour.

    • Two laser sheet cuts cross.

Star: Piercing point: Gentle piercing (laser).

Magenta

Solid: Selected laser processing.

Red

Solid:

  • Approach flag in case of laser processing: Normal approach without active path correction.

  • In case of common cut: "Scrap area" which will be cut out coherently.

  • Geometry and machining of the first part in the positioning sequence.

Dashed: Approach flag in case of laser processing: Normal approach with active path correction.

Star: Piercing point: normal piercing (laser).

Circle: Radius of spatter circle in case of piercing.

Circle (dashed): Travel motion of the cutting head to blow away the spatter residue of a pierced hole in the thick sheet (fine cutting package).

Brown

Continuous: Contour elements that have been defined as visible edges in the design of a part.

SortMaster Speed symbols and colors

In the SortMaster Speed view, symbols and lines have the following significance:

Symbol Color Description

Red

SortMaster Speed removal.

Black

SortMaster Speed removal with fixing prior to release cut.

  • If the symbol is displayed next to the removal symbol, this means: SortMaster Speed removal with fixing prior to release cut.

  • If the symbol is shown below a console, this means: this console is fixed prior to release cut.

Suction shuttle drawing

Blue

Active suction shuttle.

Suction shuttle drawing

Gray

Inactive suction shuttle.

Points (pin blocks)

Blue

Active SmartLift pins.

Points (suction shuttles)

Light green and dark green

Sensor pins for parts presence check.

  • There must be at least two sensor pins with different green coloring on the part.

  • At least one pin must be located below the part.

Areas with a colored background

Blue

Presser foot active on suction shuttle.

Suction shuttle is: highlighted in blue: The suction shuttle is taking on the presser foot function.

Green

Only for removal with fixing prior to release cut:

  • Start release for travel into the cutting area of the suction shuttle to be used for fixing prior to release cut

  • The position of the point is dependent on the positioning of the suction shuttles to be used for fixing prior to release cut.

Vertical lines (line type: dashed)

Red

Only for removal with fixing prior to release cut:

  • The lines limit the travel range of the suction shuttle to be used for fixing prior to release cut. Suction shuttles can be positioned to the side of or above this area.

  • The lines have two different functions:

    • The lines mark the collision range of the cutting head and suction shuttles to be used for fixing prior to release cut.

    • The lines indicate a minimum distance which the suction shuttle for fixing prior to release cut must maintain to the release cut point. Depending on this minimum distance, the start release for the suction shuttle’s travel in the cutting area is also positioned with a minimum distance to the release cut point. This ensures that there is a minimum residual cutting path between the start release and the release cut point to enable fixing prior to release cut. Depending on the position of the release cut point, the lines can have different distances to the release cut point.

Yellow

Arrows move suction shuttles or pin blocks in the Y direction and consoles in the X direction.

Yellow

Arrow moves all suction shuttles and all pin blocks in a synchronous movement in the Y direction. The displacement influences the length of the push-out path.

-

Push-out mode of the suction shuttles: suction shuttles are placed on the part during push-out.

-

Push-out mode of the suction shuttles: suction shuttles suction the part during push-out.

-

Push-out mode of the suction shuttles: suction shuttles are not placed on the part during push-out.


Black

Removal

  • Activate or deactivate SortMaster Speed/SmartLift consoles for removal.

  • If only suction shuttles or pin blocks from one console are active, the second console to the left or right of it can be activated.

Transport

  • Activate or deactivate SortMaster Speed consoles for transport and palletizing.

  • To obtain a more compact palletization, one SortMaster Speed console can be deactivated for transport if the remaining carrying capacity permits.

SmartGate symbols and colors

In SmartGate view, symbols and lines have the following significance:

Symbol Color Description

Purple

SmartGate removal.

The container number is displayed next to the symbol. If the removed part is a scrap part, the following symbol is displayed: *.

-

SmartGate removal with ejector cylinder.

-

Drop scrap through SmartGate.

Orange

Point in the cutting process from which processing only takes place with a deflected additional axis. The sheet rests (flying FinalCut).

Gray

Only for Drop scrap: Slug check position.

Checks whether the part has fallen through the SmartGate. If this is not the case, different measures are used on the machine to separate the part from the scrap skeleton. If these measures do not have the required effect, the contour can be recut. The Allow recutting parameter must be activated in the nesting settings for this.

-

Position of the activated ejector cylinder.

-

Deactivated ejector cylinder.

Horizontal lines (line type: dashed)

Red

Limit for the positioning of the ejector cylinder in the Y direction.

Frame (line type: solid)

Red

The vertical lines show the maximum opening of the SmartGate.

The horizontal lines represent the limits of the shaft in which the SmartGate moves.

Blue

Center of the SmartGate.

When the additional axis is not deflected, the center of the SmartGate corresponds to the tool center point.
