Chamfers and countersinks

Chamfers and countersinks can be cut using EdgeLine Bevel.

If a sheet program contains parts with an attribution, the EdgeLine Bevel user interface opens in the post-processing program and the required NC data can be created. To create attributes, EdgeLine Bevel needs to be called up in TecZone Design.

The current data collection contains all of the EdgeLine technologies.
Requirement

  • Machine control version must be at least V2.3.

  • Laser power is at least 4 kW.

EdgeLine Bevel and EdgeLine Curve are available for the following laser cutting machines (PLL01):

  • TruLaser Series 1000 (L88, L92, L94)

  • TruLaser Series 3000 (L81, L95)

  • TruLaser Series 5000 (L76)

  • TruLaser Swift Edition (L90)

Configuration

  • EdgeLine Bevel requires at least TruTops Boost version V14.4.

  • The tapping function requires at least TruTops Boost version V14.8.

  • EdgeLine Curve requires at least TruTops Boost Version V15.x.

  • In the 2D laser machine, set the machine rule variables
    EdgeLine Bevel
    to 1.

  • In the 2D laser machine, set the machine rule variables
    NCMitGrafik
    to 1.

  • Optional: In the 2D laser machine, set the machine rule variables
    EdgeLineBevelAlwaysWithDialog
    to 1 so that the EdgeLine Bevel user interface opens even if a part has no EdgeLine Bevel processing.

  • Optional: In the 2D laser machine, set machine rule variables
    EdgeLineBevelHeadlessMode
    to 1 so that the EdgeLine Bevel user interface opens when the NC file is created.

Limitations

EdgeLine Bevel and EdgeLine Curve do not work in combination with the following functions:

  • Smart Collision Prevention

  • MicroWeld

  • TwinLine

  • FlyLine

  • Chamfers, countersinks, and tappings: Mild steel is possible as a material.

  • Edge rounding: Mild steel and stainless steel are possible materials.

  • Only preset parameters can be attributed.

  • Attributions defined after NC generation are not saved in the GEO file.

  • Laser technology tables (LTT) for laser flame cutting and certain LTT for nitrogen cutting (MD5) are possible.

  • Since the EdgeLine parameters need to be technologically adapted to the cutting parameters, the use of customer-specific LTTs with simultaneous EdgeLine Bevel or EdgeLine Curve processing is not possible. If this is the case, the machine will automatically switch back to compatible TRUMPF standard LTTs.

  • For machines with retrofitted EdgeLine Bevel, the possible chamfers, countersinks and edge rounding for the relevant cutting processes and materials are shown as an overview at the end of the included document.

Create NC programs

Applies to jobs with EdgeLine Bevel contours.

  • Any changes in the EdgeLine Bevel user interface in the post-processing program are not saved in the Geo file and therefore cannot be reused in other jobs!

  • The changes are updated in TecZone Cut, not on the sheet or part. The master file is however correctly written.

  • For reasons of process technology, chamfers cannot be created on a blank (sheet size corresponds to part size).

In TecZone Cut

  1. Process the sheets manually.

  2. Press tab Start > Finish, button Create NC ▼.

    • The EdgeLine Bevel user interface opens in the post-processing program.

  3. If necessary, changes can still be made. To do this, select the part graphic.

    • These changes are saved in the master file and output to the machine.

  4. Press button Save and close NC.

    • The master file is being created.

    • The EdgeLine Bevel user interface changes to TruTops Boost in TecZone Cut.

In HomeZone

  1. In HomeZone, press the Nest button to automatically nest the parts.

    • The EdgeLine Bevel user interface opens in the post-processing program.

  2. If necessary, changes can still be made. To do this, select the part graphic.

    • These changes are saved in the master file and output to the machine.

  3. Press button Save and close NC.

    • The master file is being created.

    • The EdgeLine Bevel user interface changes to TruTops Boost in HomeZone.

Releasing NC file

In HomeZone, press button Release in the category Job in the area Sheet Program.

Create a countersink

  • This function is available in TecZone Design

  • Oxygen is used as the cutting gas. Oxygen is therefore used for flushing for processes involving nitrogen before chamfers or countersinks are applied.

  • The possible chamfers and countersinks for the relevant cutting processes and materials are shown as an overview in the data collection tables.

  1. Press tab Sheet Metal > Flat, button .

    • The drawing opens in the EdgeLine user interface.

  2. Press button Countersinks.

    • The dialog Countersinks opens.

    • An image depicts the dimensions of the preset countersink.

    • The countersinks for which a corresponding circle diameter has been found in the part are listed in a pull-down menu below the image.

  3. Select a countersink from the pull-down menu in the Countersinks dialog (for inch countersinks: Enter the diameter of the through hole), or select a core hole from the design window in the drawing.

    • The design window displays which core holes the selected countersink can be used for.

  4. Select a countersink from the pull-down menu in the Countersinks dialog.

    Depending on the material, the preset countersink depth cannot produce the desired result. In this case, the countersink depth can be changed manually by increasing or reducing the revolution speed of the cutting head.

  5. In the Processing countersinks dialog, use the + or - buttons to set the rotation depth. Press Apply to confirm.

  6. Choose Select all in the dialog.

    • The core holes highlighted in the drawing are applied.

  7. Confirm the countersink with the or the Enter key.

    • The countersink is selected. The line thicknesses depend on the technology selected.

    • The countersink is displayed in the Technologies dialog.

  8. Save the drawing in the EdgeLine user interface.

    • The attributions are applied in the .geo file.

  9. Save drawing in TecZone Design.

    • In TecZone Design, the countersink is shown as a dark green marking on the contour.

    • The attributions are saved in the .geo file.

Delet a countersink

  1. Mark one or several countersinks using the left mouse button.

  2. In dialog button Technologies, press button .

  3. Delete countersink using the right mouse button.

Create a chamfer

This function is available in TecZone Design.

  1. Press tab Sheet Metal > Flat, button .

    • The drawing opens in the EdgeLine user interface.

  2. Select Chamfer.

    • The dialog Chamfer opens.

    • An image depicts the angle and depth of the preset chamfer.

    • The selectable chamfers are shown in a pull-down menu below the image.

    • The part is displayed in the design window. The start point, center and end

    • point of a possible chamfer are indicated with points on the contours.

  3. Select a contour and apply a chamfer using one of the following methods:

    • Left-click to select a contour and apply a chamfer along the entire length of the contour.

    • Mark the start point for the chamfer on the contour using the left mouse button. Move the mouse pointer along the contour. The center or end point can be selected by pressing the left mouse button when the mouse pointer is close to the points.

    • Mark the starting point and end point of the chamfer on the contour.

    • Select the available starting point or end point and move along the contour.

  4. Select the chamfer from the pull-down menu in the Chamfers dialog.

  5. Activate checkbox Include starting point and Include end point if the chamfer is to be applied uniformly over the entire length. Is not recommended for inner contours since the part may be damaged in this case.

  6. Option for certain chamfer types: Activate if the slag needs to be removed after cutting.

  7. Confirm the chamfer with the button or with the enter key.

    • The chamfer is selected. The color and line thickness depend on the technology selected.

    • Microjoints or nanojoints are automatically created depending on the part size and thickness. A nanojoint is shown with a green point. A microjoint is shown with a blue point.

    • The chamfer is displayed in the Technologies dialog.

  8. Save the drawing in the EdgeLine user interface.

    • The attributions are applied in the .geo file.

  9. Save drawing in TecZone Design.

    • In TecZone Design, the chamfer is shown as a dark green line on the contour.

    • The attributions are saved in the .geo file.

Delete a chamfer

  1. Mark one or several chamfers using the left mouse button.

  2. In dialog button Technologies, press button .

  3. Delete chamfer using right mouse button.

Tapping countersinks

This function can be used to prepare holes for subsequent thread cutting or tapping. A countersink is made in the hole where a thread is to be cut which centers the cutting tap.

A tapping countersink is indicated by a core hole and the material thickness. The core hole is a circular inner contour in the part geometry. EdgeLine Bevel detects and creates tapping countersinks for the countersink types stored in the software.

  • Material: Mild steel and stainless steel.

  • Laser technology tables (LTT): Laser flame cutting for mild steel and stainless steel, nitrogen cutting for mild steel and stainless steel.

  • The possible tapping countersinks for the relevant cutting processes and materials are shown as an overview in the data collection tables.

Create a tapping countersink

  1. Press tab Sheet Metal > Flat, button .

    • The drawing opens in the EdgeLine user interface.

  2. Press Tapping countersink.

    • The dialog Thread is opened.

    • An image depicts the dimensions of the preset countersink.

    • The countersinks for which a corresponding circle diameter has been found in the part are listed in a pull-down menu below the image.

  3. Confirm the tapping countersink with or the Enter key.

    • The tapping countersink is marked in red. The line thicknesses depend on the technology selected.

    • The tapping countersink is displayed in the Technologies dialog.

  4. Save the drawing in the EdgeLine user interface.

    • The attributions are applied in the .geo file.

  5. Save drawing in TecZone Design.

    • In TecZone Design, the tapping countersink is displayed as a dark green marking.

    • The attributions are saved in the .geo file.

Delete a tapping countersink

  1. Mark one or more threaded holes with the left mouse button.

  2. In dialog button Technologies, press button .

  3. Use the right mouse button to delete the tapping countersink.

Edge rounding

An edge rounding is defined by the start point and end point on a contour.

Nitrogen gas is used as cutting gas.

Create edge rounding

This function is available in TecZone Design.

  1. Press tab Sheet Metal > Flat, button .

    • The drawing opens in the EdgeLine user interface.

  2. Select Edge rounding.

    • The Edge rounding dialog is opened.

    • An image depicts the radius of the preset edge rounding.

    • The selectable edge roundings are listed in the pull-down menu below the image.

    • The part is displayed in the design window. The start point, center and end point of a possible edge rounding are indicated with points on the contours.

  3. Select a contour and apply an edge rounding using one of the following methods:

    • Left-click to select a contour and apply an edge rounding along the entire length of the contour.

    • Mark the start point for the edge rounding on the contour using the left mouse button, and move the mouse pointer along the contour. The center or end point can be selected by pressing the left mouse button when the mouse pointer is close to the points.

    • Mark the start point and end point of the edge rounding on the contour.

    • Select the available starting point or end point and move along the contour.

  4. Select the type of edge rounding from the pull-down menu in the Edge rounding dialog.

  5. Activate checkbox Include starting point and Include end point if the edge rounding is to be set over the entire length without a starting point.

  6. Fast mode: Uses other parameters. The edges are rounded quicker but with less precision.

  7. Confirm the edge rounding with the button or confirm with the Enter key.

    • The edge rounding is marked. The color and line thickness depend on the technology selected.

    • The edge rounding is displayed in the Technologies dialog.

  8. Save the drawing in the EdgeLine user interface.

    • The attributions are applied in the .geo file.

  9. Save drawing in TecZone Design.

    • In TecZone Design, the edge rounding is shown as a dark green line on the contour.

    • The attributions are saved in the .geo file.

Delete edge rounding

  1. Mark one or several edge roundings using the left mouse button.

  2. In dialog button Technologies, press button .

  3. Delete edge rounding using the right mouse button.
