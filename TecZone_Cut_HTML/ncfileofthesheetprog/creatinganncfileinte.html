Create NC file in TecZone Cut

The parameters for TruLaser Center 7030 (L26) correspond to the parameters for a punching machine or punch laser machine.

If a punching machine or punch laser machine is selected, a check cycle is started when the NC file is created.

  • If Create NC is pressed in the single sheet view, an NC file is generated for the displayed sheet. To create an NC file for all sheets, the sheets must be displayed in the sheet overview.

Parameters

Settings

Field

Description

Program name

Name of the NC program. As standard, the name of the processed sheet is entered. The value cannot be changed.

NC title

This information is transferred to the NC program.

NC title corresponds to the name of the NC program by default.

Remark

This information is transferred to the NC program.

Up to 5 lines can be entered for remarks.

Post-processing program

Entries for post-processing programs or complete post-processing programs are supplied with TruTops Boost. Post-processing programs are started directly after the NC program is generated.

Select post-processing program.

Output technology tables with program

Laser technology tables and tool master data from TRUMPF are already stored in the database on the machine control. It is not necessary to output them. Own laser technology tables and tool master data that are not yet available at the machine control must be sent to the machine with the NC program. If the data is already available on the machine, the transferred values are ignored.

2D laser machine: Microjoint (changeable on the machine) active

If the function is activated, microjoints are set.

The values can be subsequently adjusted at the machine.

2D laser machine: Microjoint (changeable on the machine) with approaching

If the function is not active, the piercing point lies on the contour to be cut.

2D laser machine: Microjoint (changeable on the machine) - Length

Length of microjoints that can be adjusted at the machine

2D laser machine: Dynamic level

All parts on the sheet are machined at the selected dynamic level. The setting applies to the entire sheet.

The following values can be selected:

  • Standard: Standard dynamic level

  • Exact: Reduced dynamics with higher quality

  • Fast: Higher dynamics with reduced quality

The dynamic level can be set for single parts and contours.

2D laser machine: Subprogram technology

Certain processing sequences which are repeatedly executed on a sheet are written in a separate program (subroutine). This subroutine can be called up repeatedly within the main program.

A subroutine can be used on a machine for post-production.

Punching machine, punch laser machine or TruLaser Center 7030 (L26): Prepare loading

Only for machines with SheetMaster

Useful when the NC program is to be executed several times in succession

The timing of the loading of the next identical sheet can be set via the parameter OutputTimeTcPrepareSheetLoadForNextRun in the machine rules.

Punching machine, punch laser machine: Reload first tool at end of program

Useful when the NC program is to be executed several times in succession

The first tool in the NC program is automatically replaced at the end of the NC program.

Punching machine, punch laser machine or TruLaser Center 7030 (L26): Block numbering

If the file size of the NC program is to be reduced: Deselect option.

Punching machine, punch laser machine or TruLaser Center 7030 (L26): Strategy - Part-oriented

Certain processing sequences which are repeatedly executed on a sheet are written in a separate program (subroutine). This subroutine can be called up repeatedly within the main program.

The system searches for identical processing sequences within the active sheet. These processing sequences are written in subroutines according to the defined rules.

Punching machine, punch laser machine or TruLaser Center 7030 (L26): Strategy - Compulsory sequence

The processing operations in compulsory sequences are written into subroutines.

Punching machine, punch laser machine or TruLaser Center 7030 (L26): Minimum number of requests

Can only be specified if Part-oriented is selected.

Punching machine, punch laser machine or TruLaser Center 7030 (L26): Minimum number of processings

Can only be specified if Part-oriented is selected.

Sequence

Field

Description

Vaporize all

The vaporizing type must be included in the technology table. The Vaporizing option must be activated in the rules.

The following vaporizing types can be selected:

  • Point

  • Circle

  • Contour

No vaporizing

2D laser machines: No vaporization.

Punch laser machines: The default setting is No vaporizing. If the vaporizing for a raw material with a defined vaporizing type is to be created during automatic processing and output in the NC program, Vaporize according to process rule must be activated manually.

Vaporize according to process rule

The values are read out from the selected rules.

Punching machine, punch laser machine or TruLaser Center 7030 (L26): Bring processing forward - No

Vaporizing is not preferred. The processing sequence is not changed.

Bring processing forward - Part by part

Vaporizing is preferred for each part. This means that, on each part, the protective film is vaporized first before the part is cut.

If processings are preferred, re-entry in an NC program and post-production on the machine are not possible.

Bring processing forward - Over the entire sheet

Vaporizing is preferred for the complete sheet. This means that the protective film on the entire sheet is vaporized first before the rest of the processings are executed.

If processings are preferred, re-entry in an NC program and post-production on the machine are not possible.

Selectable operation

Sheet position

Field

Description

Measure sheet position

When machining a sheet, its length must be known with sufficient accuracy. To guarantee this, the sheet must be loaded or measured precisely.

The settings made in Sheet position refer to the entire program. Interactive measurements already set are not affected by this and are executed in any case.

What selection options are available depends on whether an interactive measurement was set.

  • Do not measure

  • Measurements set interactively only

The sheet position is not measured. For an interactive measurement: The sheet position is only measured within the scope of interactive measurements already set.

  • With height regulation

  • Interaction + distance regulation

The machine measures the position of the sheet edge with the distance regulation. For interactive measurement: The machine measures the position of the sheet edge with distance regulation in addition to the interactive measurements already set.

  • with DetectLine (Cateye)

  • Interaction + DetectLine (Cateye)

The machine measures the position of the sheet edge with DetectLine or Cateye. For interactive measurement: DetectLine measures the exact position using different measuring methods in addition to the interactive measurements already set.

Depending on the control version, the following measurement functions can be selected:

  • one outer corner: DetectLine measures the exact position of an outside corner of a rectangular pre-cut part or sheet.

  • one inner corner: DetectLine measures the exact position of a rectangular inside corner.

  • two inner corners: measures the exact position of two rectangular inside corners.

  • one round hole: DetectLine measures the exact position of the center of a round hole.

  • two round holes: DetectLine measures the exact position of the centers of two round holes.

  • Round hole + inner corner: DetectLine measures the exact position of the center of a round hole and the exact position of a rectangular inside corner.

Measure approx. position with height regulation first

The checkbox is only displayed if the sheet position is measured with DetectLine.

In addition to the measurement with DetectLine, the machine measures the sheet position with distance regulation before beginning the cut.

The sheet position is detected even though the sheet is imprecisely inserted.

Loading - manual

Machine is loaded manually.

Loading - automated

Machine is loaded automatically. Loading with individual suction cups or suction cup groups is possible.

Loading - with LiftMaster in single pallet mode

Machine is only loaded from one machine pallet.

Loading - Pallet change before MP

A pallet change takes place before the start of the main program.

Loading - Pallet change after MP

A pallet change takes place at the end of the main program.

Loading with LiftMaster: Machine is loaded with LiftMaster.

With drawing unit: Machine is loaded with the extension device using LiftMaster. This way, the insertion position of the sheet is more precise. The with drawing unit checkbox can only be activated if the integrated sheet alignment option is available at the LiftMaster. Integrated sheet alignment is available for the following LiftMaster variants:

  • LiftMaster Sort (1.5 x 3 m)

  • LiftMaster Sort (2 x 4 m)

  • LiftMaster (2.5 x 4 m)

Unloading - Do not unload scrap skeleton with LiftMaster

Only available if SortMaster is configured for the machine

The scrap skeleton is removed with SortMaster. Not possible if with LiftMaster in single pallet mode is active

If the SortMaster has already removed the scrap skeleton via sectional removal: select the Do not unload scrap skeleton with LiftMaster checkbox. That prevents the LiftMaster from attempting to remove the scrap skeleton, although the scrap skeleton was already removed by the SortMaster via sectional removal.

Creating an NC file

Procedure in TecZone Cut

  1. Process sheets in succession in the single sheet view if necessary.

  2. Save changes.

  3. Adjust the parameters for the NC file:

    • Press tab Start > Finish, button Create NC ▼.

    • Select Parameters…​.

  4. To create an NC file for a single sheet:

    • Display sheet for which the action is to be carried out in the single sheet view.

    • Press tab Start > Finish, button Create NC.

    • An NC file is created for the sheet displayed.

  5. To create an NC file for all sheets:

    • Change to the sheet overview by pressing the All sheets button.

    • Press the Create NC button.

  6. To release the NC file in HomeZone:

    • Save changes.

    • Close TecZone Cut.

    • In HomeZone, press button Release in the category Job in the area Sheet Program.

  7. To release the NC file in TecZone Cut:

    • Save changes.

    • Press Start > Finish, button Release production package.

Requirement

  1. Press tab Start > Finish, button Create NC ▼.

  2. Save changes.

  3. Close TecZone Cut.

  4. In HomeZone, press button Release in the category Part in the area Cutting Programs.
