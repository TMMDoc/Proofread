Configure automatic processing

  1. To change the settings for automatic processing: Open tab Technology > Create automatically button All [active configuration] with ▼.

  2. Select area Adjust…​.

  3. Select the required configuration in the first selection field.

  4. For punching machines and punch laser machines: set parameters for the areas Sample, Punching and Laser.

    For TruLaser Center 7030 (L26): set parameters for the area Laser.

  5. To save the changes in the current configuration: Press the Save button.

    • The modified configuration is automatically active.

  6. To save the settings in a new configuration: Press the Save as …​ button:

  7. Enter name for the new configuration.

  8. Press the OK button.

    • The new configuration is automatically active.

  9. To delete the current configuration: Press the Delete button.

  10. To activate and apply a different configuration:

    • Press the All ▼ button.

    • Select a new configuration.

    • Configure removal methods.
