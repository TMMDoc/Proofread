Create a punching tool

Change a tool drawing

  • The tool drawing can be modified or recreated for the following tool types:

  • Special

  • Form

  • Roller cutting

  • Roller pinching

  • MultiBend

  • Quick forming

  • The following options are available:

  • Select new drawing.

  • Edit an existing drawing.

Requirement
Single part view, part overview, single part mode or contour mode is active.

  1. On the main functions toolbar, press Activate the tool..

  2. Select Punching tab.

  3. Activate checkbox Selection and select tool type.

  4. Select tool in the list.

  5. Press the Modify button.

    • The Change tool dialog appears.

  6. To select a new tool drawing:

    • Select Select drawing in the selection field below the preview window.

    • Select the desired *.tool file.

  7. To edit an existing tool drawing: select Edit drawing in the selection field below the preview window.

    • TecZone Design opens.

  8. Edit the tool drawing.

    • The line color of the tool contour must be CYAN.

    • The tool contour must be closed.

  9. To change the color of the tool contour:

    The menu Construction must be selected.

    • Create a selection frame around the drawing.

    • In the Properties panel at Appearance, click on the color displayed.

      The selection field appears.

    • Select tab Web.

    • Select the color Cyan.

  10. Press File button Save.

  11. Press File button Close.

    • The new tool drawing appears in the preview window.

Copy data records of tapping tools

Tapping tool data records can be copied from one material to another. This means that material-dependent and material-dependent data records do not have to be created for each tapping tool.

Incorrectly allocated tapping tool data can lead to destruction of the tapping tool!

  • Use only tapping tool data from the "Tapping" technical information from TRUMPF.

  • The correct tapping tool data must be allocated to the correct material.

  1. Prerequisite: single part view, part overview, single part mode or contour mode is active.

  2. On the main functions toolbar, press Activate the tool..

  3. Select Punching tab.

  4. Next to Selection, open the selection field with .

  5. Select the tool Tapping.

  6. Select tapping tool.

  7. Press the Modify button.

  8. Press the Edit button.

  9. Press the Copy button.

  10. Select Source material spec. and Target material spec..

  11. Press the OK button.

Create a film slitting tool

To facilitate peeling off a protective film, a special "peeling contour" in the shape of a row of jagged teeth can be made with a film slitting tool. This peeling contour is known as a film peeling assistant. The film slitting tool is managed in tool management under the type Engraving as Film slitting.

In the punching parameters, the options Marking and Engraving before marking must be active for automatic processing with the film slitting tool.
Requirement

  • The "film cutting tool" option is available on the machine.

  • For older Boost versions, the Remove protective film function can only be used on 3D parts.

Settings

  1. Call up Data Manager Cut.

  2. Activate the machine options Carving and Marking in the machine configuration.

  3. If necessary, change the Identity number of the film slitting tool in the system rules variable IdentNumberFoilRemovalTool.

Define the peeling contour

  1. See chapter "Cutting preparation" in the TecZone Design Help. It defines where the peeling contour is to run on the part

    Example: The separating line is displayed as yellow dotted marking.

Create a processing sample

This is another option in TecZone Cut to create processing samples for a film slitting tool.

A processing sample is suitable for recurring processing sequences.

  1. Press tab Technology >_On contour_.

  2. Select At element.

  3. Click on the elements one after the other.

    • Elements are displayed in cyan.

  4. Press tab Processing sample >_Management_, button Create…​.

  5. When creating the Processing sample, the query Select element or click OK appears.

  6. Select an element.

  7. Press the OK button.

    • The selected elements are displayed in magenta.

    • The message Click on further processing and confirm with OK is displayed.

  8. Select the next element.

    • The selected element is displayed in magenta.

  9. Press the OK button.

    • Dialog Save processing samples opens.

  10. Enter a name for the processing sample. If necessary, adjust the presettings.

  11. Save the processing sample.

Activate film slitting tool

This option is available in TecZone Cut.

  1. In tab Technology, press button and select Adapt.

  2. In the Punching parameters activate the checkbox Marking and Engraving before marking. Save changes.

  3. Display sheet for which the action is to be carried out in the single sheet view.

  4. Press tab Technology >_Single part_, button Start.

  5. Mark the contour of a part.

  6. Press to the right of the tool display.

    • The Tools dialog is displayed.

  7. Select Punching tab.

  8. Select Selection in the upper right.

    • A list with the selectable tools is displayed.

  9. Select the Engraving tool type.

    • The tools that can be used for engraving are displayed.

  10. Select Film separation, or alternatively the self-defined film cutting tool.

  11. Press the OK button.

    • The cutting mark of the part is color-coded in cyan.

  12. To transfer the single part processing to other parts on the sheet: Press Apply.

  13. Enter or select the parameters.

  14. Press the OK button.

Create a new tapping tool

If a tapping tool is selected for processing, the other parameters for the tapping tool are assigned automatically. The assignment depends on the machine, material, material thickness and extrusion. The basis for these parameters is formed by the parameters for metric threads in the "Tapping" Technical information. This data can be adapted each time it is applied.
Requirement
Single part view, part overview, single part mode or contour mode is active.

  1. On the main functions toolbar, press Activate the tool..

  2. Select Punching tab.

  3. Press the Create button.

  4. Select Thread former.

  5. Press the Continue button.

    • Dialog Create Tapping Tool opens.

    • The field Name is empty.

    • A new tapping tool can be created. All data must be entered manually in the database.

  6. In the field Tapping tool data, press the button Edit.

    • Dialog Create Tapping Tool opens.

  7. Enter the tapping data and press the OK button.

    • Dialog Tapping Tool Data Management opens.

  8. Enter data in the Data depend.on material and thickness tab.

  9. Press the Create button.

    • The entries are saved.

  10. Enter data in the Data depend.on material and machine tab.

  11. Press the Create button.

    • The entries are saved.

  12. Press the OK button.

  13. Calculate Identity number and generate comment: Press the Suggestion button.

  14. Enter own Identity number and comment.

    • If Suggestion is pressed: The Identity number is calculated. It is made up of the number and the dimensions of the tool.

  15. Press the Close button.

  16. To transfer the tool to the database: Press the Yes button.

    • The tapping tool is created.

Create a standard tool

Standard tool parameters

Field Description

Forming type

For forming tools only

Dimensions

Depending on the selected tool, define the dimensions A1 to A6.

The tool length A 1: must be greater than the tool width A 2:. Define the rotated tools using the mounting position.

Or: Press the …​ button to define the dimensions in the Tool parameters dialog.

Tool drawing

The tool drawing can only be changed for certain tool types (see Special tool). For standard tools, the tool drawing is automatically generated from the data.

The punch of the tool is always depicted in the tool drawing. This figure is important for forming tools, for example, to determine the forming direction.

Obstruction or die contours can be drawn in the tool drawing.

A tool drawing can be modified or recreated in the selection field below the preview window. The following options are available:

  • Change a tool drawing.

    • Select drawing.

    • New drawing.

    • Edit drawing.

  • Create a special tool.

Only for tool types permitted for integrated flattening

To generate flat sheet areas with the Integrated flattening function, tools with Chamfer height are used.

PU stripper

  • None

  • Round

  • Rectangle

ID No.

To allow the identity number to be calculated and to generate a comment: Press Suggestion.

The ID No. is calculated. It is made up of the number and the dimensions of the tool.

Customer-specific

  • A maximum of 15 characters, as desired, are permitted

  • Can be used as the filter criterion to search for a tool.

Mat.thickness

  • min: Value for minimum permissible material thickness

  • max: Value for maximum permissible material thickness

Sheet stamping

For forming tools and threads with extrusions

  • Undefined

  • on upper sheet side: The sheet metal plating is on the upper side of the sheet.

  • on lower sheet side: The sheet metal plating is on the underside of the sheet.

The forming direction is taken into account during import and export.

Mounting position and positioning

Enter value for Mounting position (a):.

Cartridge type

  • Steel

  • RTC

  • Size 5

Die type

  • Normal

  • Integrated flattening

  • Beveled

Whispertool

A tool with a beveled punch is called Whispertool. The Whispertool reduces the punching force. A noise reduction of up to 50 % is achieved.

Activate if the tool is a Whispertool.

Punch breakage control

The punch break sensors provides an early report of damage to the punch. Before every tool change to the punch adapter of the punching head, the linear magazine checks whether the contour in the sheet is completely punched out at the last programmed position for this tool.

Activating the punch break sensor is only useful for punches with small diameters.

only for active/descending die

Disable

  • Punch break sensors are only practical for punch with small diameters.

  1. If the punch break sensor is to be activated for the tool: Activate checkbox Punch breakage control.

  2. If the tool is only to be used on machines with an active or descending die: Activate checkbox only for active/descending die.

  3. To exclude a tool from processing: Activate checkbox Disable.

  4. For further tools, press the Continue button.

    An incomplete MultiTool cannot be saved.

  5. Select the Close button.

  6. To transfer the tool to the database: Press the Yes button.

Creating a tool drawing for special tools

This section describes how to create a tool drawing for special tools for punching machines and punch laser machines.

Sometimes it is necessary to create a tool with special geometries that is therefore not included in the standard database. Before such a tool can be added to the database, the tool geometry must be drawn in TecZone Design. Alternatively, CAD drawings can be imported in TecZone Design.

  • The tool drawing can be modified or recreated for the following tool types:

  • Special

  • Form

  • Roller cutting

  • Roller pinching

  • MultiBend

  • Quick forming

Tool drawings: Colors and symbols

Color Meaning

Cyan

Punch contour or die contour

Red

Obstruction or collision contour of the tool

Yellow circle

Self-stripping PU stripper

Arrows

Permissible relative direction of travel of the tool
Requirement
Single part view, part overview, single part mode or contour mode is active.

Create a new tool drawing

  1. On the main functions toolbar, press Activate the tool..

    • Dialog Tools opens.

  2. Select Punching tab.

  3. Press the Create button.

    • The dialog Create tool opens.

  4. Select Standard as tool class and press the Continue button.

    • Dialog Tool type selection opens.

  5. Select 9 Special as tool type.

    • The dialog Create tool opens.

      The storage location must not be changed. All punching tools must be in the pre-selected directory.

  6. Open the pull-down menu below the graphic. Select New drawing.

    • The file explorer opens.

  7. Enter a name for the new tool file.

  8. Confirm with button Save.

    • A new drawing is created as a *.tool file and is opened in TecZone Design.

Create a tool drawing in TecZone Design

  1. Draw the tool with the functions in the tab Design > Sketch.

    • Create tool contours in the color cyan. If necessary, Change the color of the tool contour.

    • Check that the tool contours are closed.

    • The tool center point is defined as the drawing center. The tool center point must be located at the coordinate origin. Other markings such as "*" are not permitted and are not recognized as the tool center point.

  2. In the menu select Design.

  3. Create a selection frame around the drawing.

  4. In the Properties panel at Appearance, click on the color displayed.

    • A selection field with 3 tabs appears.

  5. Select tab Web.

  6. Select the color Cyan.

  7. Save tool drawing.

  8. With button X, close TecZone Design.

    • In the Create tool dialog, the tool is displayed in the preview.

Create a tool drawing based on a DXF file

This is an alternative method in TecZone Design to create a tool drawing.

In TecZone Design, 2 tabs are opened: A tab "Design1" and a tab with the name of the new drawing. It is processed in the tab of the new drawing.

  1. Create a selection frame around the drawing.

  2. In the panel Structure > 2D import, click using the right mouse button. Select Activate curve container in the dialog.

  3. Mark and delete the drawing.

  4. Delete the tab of the drawing "Design 1".

    The operating procedure is described on the basis of a DXF file.

  5. Set File > Open > Type AutoCAD (*.dwg, *.dxf ).

  6. Check the model space units and, if necessary, change to millimeters.

  7. Import the DXF file.

    • A new "Design1" tab opens.

      Tool contours must be closed.

  8. Drag the selection frame around the drawing and copy by pressing Ctrl+C. Select "Design2" tab and insert by pressing Ctrl+V.

  9. Tool contours must be created in the color cyan: Enter the color "Cyan" in the window Properties > Appearance in the line color.

    • The tool contour is displayed in cyan.

      The tool center point is defined as the drawing center. The tool center point must be located at the coordinate origin. Other markings such as "*" are not permitted and are not recognized as the tool center point.

  10. Select the Move function in the Sheet Metal tab.

  11. Select Up to tool guide. If necessary, zoom in to get a better view of the point of origin.

  12. With the mouse button pressed, pull the blue point of the drawing center on the blue point of the origin .

    • The tool center point is in the coordinate origin.

  13. Mark the drawing and click the origin.

  14. Press File > Close.

    • Drawing has the correct dimensions and a drawing center point.

    • Drawing is available in tool management and can be applied.

  15. Save tool drawing.

  16. Close TecZone Design with "X".

    • TecZone Cut is displayed.

    • In the Create tool dialog, the tool is displayed in the preview.
