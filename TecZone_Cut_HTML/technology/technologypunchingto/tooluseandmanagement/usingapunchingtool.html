Using a punching tool

The selected machine workstation, the material and the active tool are displayed on the main functions toolbar.

The punching tool management is opened via the Activate the tool. button in the main functions toolbar.

Selection criteria

Field Description

Selection

Reduces the search result to tools of a certain tool type.

ID No.

Identity number

Remark

Value which was entered in the Remark field when the tool was created

Dim.1

Tool shape and dimensions. For metric tools (mm), for inch tools (in)

Dim.2

Tool shape and dimensions. For metric tools (mm), for inch tools (in)

Customer-specific

Value which was entered in the Customer-specific field when the tool was created

Show only MultiTools

Reduces the search result to MultiTool tools.

For current sheet thickness only

Reduces the search result to tools which are suitable for the current sheet thickness.

Show inhibited tools only

Reduces the search result to the disabled tools.

Show only tools from the master tool list

Reduces the search result to tools from the master tool list.

This selection criterion is only displayed if the machine rule variable
MasterToolList
is enabled.

Using a punching tool

Requirement
Prerequisite: single part view, part overview, single part mode or contour mode is active.

  1. On the main functions toolbar, press Activate the tool..

  2. Select Punching tab.

    • All tools supported by the current machine are displayed.

  3. Select tool or activate selection criteria for filtering.

  • To display the geometry and dimensioning of the tool: Right-click on a tool and select Tool drawing.

  • To sort the list of available tools: Click to the right next to the heading line .

  • To convert Dim.1 and Dim.2 from inch or gauge into millimeters: right-click in the respective input field.

  1. Press the OK button.

    • The tool is activated and is displayed in the main functions toolbar.

Using a roller cutting tool

Roller cutting tool parameters

Field Description

Feed

Speed of the machine axes.

BDC position

Plunging depth. Move the mouse over the processing operation to have the LDP value displayed.

Retract path

Travel motion at the upper dead point (UDP) in the opposition direction to the last machining operation (in case of circles, the motion is tangential to the last position). Purpose: to release a sheet which may have got stuck.

Separation punch

Inside corners must be punched free with at least 6 mm.
Requirement

  • The Roller tools option is present at the machine and activated in the Data Manager Cut.

  • One of these views is active: Single sheet view, part overview, single part mode or contour mode.

  1. On the main functions toolbar, press Activate the tool..

  2. Select Punching tab.

    • All tools supported by the current machine are displayed.

  3. In the Selection field, select the Roller cutting tool type.

  4. Select tool in the list.

  5. Press the OK button.

  6. Enter or select the parameters.

  7. Press the OK button.

  8. Create Processing At element or At contour.

Using the roller deburring tool

The roller deburring tool is used to deburr the sheet by moving the sheet between two rollers. The rollers are located in the punch and die. Only burrs created during punching are embossed.

  • If the deburring operation is programmed after punching and both processing steps overlap partially or completely, the contour is punched and deburred automatically after optimization.

  • If the deburring process is programmed before punching, the processing sequence must be defined interactively via compulsory sequence or optimization levels.

  • Inner contours are deburred after separation.

  • Outer contours must be connected to the scrap skeleton via microjoints or the web of the separation stroke for deburring. At these points the deburring process is cut manually.

Requirement

  • The Roller tools option is present at the machine and activated in the Data Manager Cut.

  • The roller deburring tool has been created as standard tool with tool type 37 (_Roller deburring).

  • The contour is processed using a punching tool.

  • Single part view, part overview, single part mode or contour mode is active.

Manual cutting-off deburring processing

  1. Press tab View > Show / Hide, button Active tool.

  2. Click on the deburring processing of an element with disposal or microjoint.

  3. Press tab Technology > Edit, button Technology.

  4. Tool guide DIVIDE/JOIN, press the Split processing button.

  5. Cut off the deburring processing at the separation stroke or microjoint.

  6. Click on the two deburring processes. Move the yellow arrows to shorten the width of the separating stroke or the microjoint.

Using the ball deburring tool

The ball deburring tool is used to deburr the sheet by moving the sheet between two balls. The balls are located in the punch and die. This function can be used to emboss the burr that is created during punching. In addition, laser-cut inner contours or manually exposed laser edges can be deburred if they allow the movement of the ball deburring tool.

Separated deburring processing operations or deburring processing operations created on single elements are not linked together. When optimizing, the processing direction can be changed. If this should not be allowed, the correct order must be defined using a compulsory sequence.

The offset of the deburring processing is normally preset to 1 mm. The offset can be set in the punching parameters or in the system rules variable OffsetEntgravingDeburring. The value stored in the process rules is displayed in the punching parameters. A change of the value in the punching parameters is automatically transferred to the process rules.

For open contours, the processing is applied without offset to element.

When deburring laser-cut inner contours, the ball deburring tool does not run along the rounding radii of the laser paths.

  1. The offset for the pending processing, for example, TwinLine, can be quickly changed via the punching parameters.

  2. To set a ball deburring tool as the active tool, snap the corner of the deburring operation with the mouse. A round symbol is displayed.
A change in the offset value in the process rules or in the punching parameters affects all users of TruTops Boost system-wide.
When creating the deburring processing, it is possible to work with optimization planes so as to define the desired optimization sequence.

  • Before generating the deburring processing, processing must first be programmed on a contour.

  • Inner contours are deburred after separation.

  • Outer contours must be connected to the scrap skeleton via microjoints or the web of the separation stroke for deburring. At these points the deburring processing must be cut manually. An outer contour can no longer be deburred after separation.

Requirement

  • The Engraving option is available on the machine and activated in Data Manager Cut.

  • The ball deburring tool has been created as standard tool with tool type 33 (_Engraving). The tool length A 1: is defined.

  • The identity number of the ball deburring tool is stored in the machine rule variable IdentSphericalDeburringTool.

  • The contour has been processed.

  • Single part view, part overview, single part mode or contour mode is active.

  1. On the main functions toolbar, press Activate the tool..

  2. Select Punching tab.

  3. In the Selection field, select the Engraving tool type.

  4. Select tool in the list.

  5. Press the OK button.

  6. Enter feed (speed of the machine axes).

  7. Press the OK button.

  8. Press tab Technology > Create manually, button Contour.

  9. To set the offset of the ball deburring tool:

    • Tool guide SETTINGS, press the Punching parameters…​ button.

      The dialog Punching presettings opens.

    • Under Ball deburring, adjust the parameter value Offset.

    • Press the OK button.

  10. Create Processing At element or At contour.

  11. For outer contours: Manual cutting-off deburring processing.
