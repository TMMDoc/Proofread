Punching machines and punch laser machines: Technology > Roller technology

Punching machines and punch laser machines: Technology > Roller technology

When processing with roller tools, the sheet is moved between two steel rollers. The steel rollers are in the punch and in the die.

Pull-processing

Using this function, roller processing operations that include pushing processing lines can be converted into purely pull-processing. To do this processing operations are cut open if necessary and the direction of the individual processing lines is set so that they are only pull-processed.

Roller processing operations that belong together are automatically set in a compulsory sequence so that these processing operations can be carried out in succession.

Push-processing should be avoided to reduce the risk of wavy sheets.

Ⓐ Pull-processing is not programmed: Roller processing contains pushing (1) and pulling elements (2).
Ⓑ Pull-processing is programmed: roller processing is separated and contains only pulling elements (3, 4).

As roller processing operations are frequently merged and lie close to each other, the compulsory sequence is not always displayed. The Properties - Processing function on the mini toolbar can be used to check if the selected roller processing operation is a compulsory sequence.

At the separating points of the individual contour sections, an overlap can be inserted.

On the following machines, pull-processing can be used to program gradual plunging and emerging:

  • Machines with an active die (TruPunch 5000 [S10], TruPunch 5000 [S12], TruMatic 7000 [K02], TruMatic 7000 [K08])

  • TruPunch 3000 (S11) from version V02.00 and higher

  • TruMatic 1000 (K07)

The Pull-processing with gradual plunging function creates an overlap of 5 mm by default. This value can be adjusted in the machine rule variables SanftesEintauchen_Overlap geÃ¤ndert.

For the function Pull-processing with gradual plunging to be displayed in the menu, the correct control version of the machine must be entered in the machine rule variable MaschCtrlVersion.

Parameters Pull-processing with gradual plunging

Parameter Description

Plunging length

The length of the path during the gradual plunging process at the start of processing. 50 mm by default

Emerging length

Length of the gradual emerging process at the end of processing. 50 mm as standard

Target depth

Describes the depth to the tool should move down to during the gradual plunging process. The target depth depends on the selected tool and is equivalent to the forming height of the roller forming tool.

With Properties - Processing function in the mini toolbar can be used to check the values entered.

Programming pull-processing

  1. Process contour with roller tool.

  2. Press tab Technology > Roller technology, button Pull-processing.

  3. To create a pull-processing operation with overlap:

    • Press the with overlapping button.

    • Click on a contour or create a selection frame around several contours.

    • Enter the length of the overlap in the input line and press the Enter key to confirm. The overlap is 50 mm by default.

  4. To create a pull-processing operation without overlap:

    • Press the without overlapping button.

    • Click on a contour or create a selection frame around several contours.

  5. Create a pull-processing operation with gradual plunging and emerging:

    • Press the with gradual plunging button.

    • Click on a contour or create a selection frame around several contours.

    • Enter the following parameters in succession at the input line: Plunging length, emerging length and target depth.

Gradual plunging

When a contour is produced using a roller tool, particularly a roller beading or roller offsetting tool, a clear marking is left at the starting point. Using the Gradual plunging function the plunging and emerging of the tool is delayed such that it enters or comes out of the sheet on an angle. The tool can travel this path again afterwards. A disruptive approach mark no longer occurs.

More information on roller offsetting and roller beading tools is given in the "Roller offsetting and roller beading" tool information provided with the tool.

Gradual plunging and emerging can be programmed for the following machines:

  • Machines with an active die: TruPunch 5000 (S10), TruPunch 5000 (S12), TruMatic 7000 (K02), TruMatic 7000 (K08)

  • TruPunch 3000 (S11) from version V02.00 and higher

  • TruMatic 1000 (K07)

For the function to be displayed in the menu, the correct control version of the machine must be entered in the machine rule variable MaschCtrlVersion.
Parameter Description

Plunging length

The length of the path during the gradual plunging process at the start of processing

Emerging length

Length of the gradual emerging process at the end of processing

Starting depth

Describes the depth to the tool should move down vertically before the gradual plunging process. The value is 0 mm by default. Enter a different value is special cases.

Target depth

Describes the depth to the tool should move down to during the gradual plunging process. This corresponds to the forming height of the roller forming tool.

Programming gradual plunging and emerging

  1. Process the contour with a roller offsetting or roller beading tool.

  2. Press tab Technology > Roller technology, Gradual plunging.

  3. Click on the roller processing operation for which the Gradual plunging is to be programmed.

  4. Select the end point of the roller processing operation:

    • To process a complete roller tool path using the Gradual plunging function: click on the last element of the roller tooth path.

    • To process one element only with the Gradual plunging function: click on the same roller processing operation again.

  5. Enter the following parameters in succession at the input line:

    • Plunging length

    • Emerging length

    • Starting depth

    • Target depth

The function Properties - Processing in the mini toolbar can be used to check the values entered.

Avoiding approach marks

For machines for which the function Gradual plunging is not available, approach marks can be avoided with closed contours. Requirement: The overlap at the contour starting point is set to 50 mm and the stroke speed is set to 10 %.

  • The feedrate potentiometer at the machine control must be set to 100 %.

  • If a contour is to be produced with two or more attempts to avoid push-processing, an approach mark is made at the end of the first attempt.

  • More information on roller offsetting and roller beading tools is given in the "Roller offsetting and roller beading" tool information provided with the tool.

  1. Process the contour with a roller offsetting or roller beading tool.

  2. Convert contour into pull-processing.

  3. Enter an overlap of 50 mm.

  4. Optimize processing sequence automatically. To do this, press tab Optimization > Optimize, button Start.

  5. When Confirm list appears: Press the Continue button.

    • The dialog Processing optimization opens.

  6. Press the Continue button.

  7. In the list of the tool sequence, select the roller beading tool or roller offsetting tool.

  8. Press the Separate part by part button.

  9. In the field Punching stroke speed: Down:, enter the stroke speed 10 %.

  10. Press the OK button.
