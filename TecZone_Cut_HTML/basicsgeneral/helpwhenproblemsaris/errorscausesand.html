Errors, causes and solutions

Errors, causes and solutions

Assembly

Error or warning Cause Solution

  • Part is an assembly

  • This part is an assembly which cannot be processed directly.

The part is made up of several components.

Break down the assembly automatically, or identify the components and break it down.

For a single bending part:

  • Select alternative Prepare 2D files.

  • Repair the part manually.

The geometry model has an invalid structure. The component contains several solids. They will need to be corrected in the structure tree.

The part is made up of multiple solids or the structure contains superfluous elements.

  • Check whether the additional solids arose from internal collisions.

  • Change the length of overlapping tabs or the bend deduction value. Delete unnecessary solids.

Raw material does not exist.

No raw material or material was assigned to the part.

  • If a thickness is stored in the file, select Create a material.

  • If no thickness is stored in the file, select raw material.

Bending program

Error or warning Cause Solution

This program is not based on the current version of Design. Reboost the bending program to apply the changes in Design to the bending program.

The part was edited in TecZone Design. Bend deductions have changed, so the calculated bending program no longer matches the current design.

  • Open the bending program in TecZone Bend.

  • Edits are transferred to the new design.

Geometry

Error or warning Cause Solution

Geometry models in 'Design' and 'Bend' differ for the following bending operations: {0}

The design radius is used in the bending program. The design production radius is taken into account for the cut geometry. The design production radius is created by the assignment of the tools. The bending operations are thus simulated in the bending program with the non-updated radius with incorrect width, and deviating stop positions are calculated.

  • Manually increase affected notches in Design.

  • Select lower tool with smaller width or upper tool with a smaller radius.

  • Re-calculate bending program.

Geometry model invalid: Please create missing notches also for operations "Before/After bending process"

Changes to the bend radius in the bending zone are not visualized in TecZone Design but are included in the unfolding. When a bending program is created, a new part is generated from the design and radii are adjusted. If an adjacent notch is too small when the radius is increased, the part can no longer be unfolded.

Unfoldability must also be guaranteed for bendings manufactured "Before bending operation" or "After bending operation".

  • Switch to TecZone Design.

  • Change the notches of the highlighted bendings in the geometry model.

  • Re-calculate the bending program.

Geometry model invalid: Problem with bend radii

Some roundings are not cylindrical and can therefore not be identified as bends.

Convert all non-cylindrical roundings into cylindrical roundings and identify them as bends.

Predefined thickness is different from the thickness read from imported file. Thickness in imported file was: {0}

A raw material was selected whose thickness does not match the thickness stored for the geometry in the imported file.

Change the selected sheet thickness or have the part calculated. Assign material and sheet thickness (in HomeZone: create a part or import a geometry).

Predefined material is different from the material read from imported file. Material in imported file was: {0}

The selected raw material does not match the material stored for the geometry in the imported file.

Change the selected sheet thickness or have the part calculated. Assign material and sheet thickness (in HomeZone: create a part or import a geometry).

Sharp-edged seams or roundings with inside radius = 0

  • Check whether there are sharp-edged seams or bends with an inside radius = 0.

  • Correct the inside radius.

The part contains unsupported geometry elements.

Check geometry.

  • The following geometric elements are not supported:

    • Non-cylindrical bends

    • Bending surface which is divided into 2 or more part surfaces

    • Double-sheet bending and S bends

Material not applicable for bend processing

The material is not approved for bending processing.

  • Select the material in the Material category in HomeZone.

  • Check the setting in the field Processing Technology.

  • If a bending program is to be created: Select another material.

Part is corrupt.

The internal geometry model is corrupt.

Check geometry. To do this, reset the Sheet Metal property to Incorrect in the sheet metal part’s properties. Convert the part back into sheet metal.

Bending angle of a bend > 180°

A bend has an angle exceeding 180°.

To program the part, select After Bend Processing as the bending process, or use segment bending.

Backgauge

Error or warning Cause Solution

Retraction position cannot be reached for bending operation {0}.

The retraction position cannot be reached for this bending operation.

Instable backgauge strategies at bending operation {0}.

One contact finger is located at position 'Clamp', the other contact finger is located at position 'None'.

Retract backgauge.

Contact fingers and part collide during bending process {X} - process step {X}.

The collision check has detected a collision between two objects.

Change backgauge retraction parameters like direction and distance.

Machine

Error or warning Cause Solution

Selected machine is not suitable for this part.

This part cannot be produced with this machine.

Switch to the machine in HomeZone.

Material

Error or warning Cause Solution

Material not suitable for bend processing

The material is not approved for bending processing.

  • Select the material in the Material category in HomeZone.

  • Check the setting in the field Processing Technology.

  • If a bending program is to be created: Select another material.

The raw sheet '{Name}' could not be deleted because it is still being used in jobs or job templates. ({Code})

Raw sheets are used in jobs or job templates.

Release or delete job or job template.

A stock still exists for raw sheet '{RawSheetName}'. It can therefore not be deleted. ({Code})

Raw sheets with a net stock or gross stock > 1 cannot be deleted.

Reduce the stock of raw sheets to 0.

Error while creating setup plan PDF. No valid default printer selected on TruTops Boost Server. Please check log file and printer settings.

There is no standard printer stored in the operating system for TruTops Boost.

    • The standard printer must have the "connected" status.

    • Access may not be bypassed or interrupted.

    • A PDF or XPS printer can also be used as the standard printer.

Contact Technical Service.
