General

General

TruTops Boost is software for part design and continuous programming of 2D laser, punching, punch laser and bending machines. It provides automatic processing and monitoring from order to finished NC file, and accounts for dependencies between the linked technologies: design, bending, nesting, cutting and punching.

TruTops Boost has two user levels:

  • HomeZone - Uses BOOST technology to automatically calculate processes.

  • TecZone - Adapts each program interactively and calculates it in substeps. BOOST can also be started from TecZone Cut to calculate a complete job.

HomeZone

Use HomeZone to:

  • Manage and centrally control orders, jobs, job templates, parts and materials.

  • Create bending programs, cutting programs and sheet programs.

  • Automatically calculate (BOOST) bending programs and sheet programs.

  • Navigate to TecZone.

TecZone

Use TecZone to:

  • Analyze 3D designs and manually process geometries (TecZone Design).

  • Display details and manually correct sheet programs for 2D laser cutting machines, punch laser machines and punching machines.

  • Calculate cutting programs.

  • Automatically calculate (BOOST) jobs.
