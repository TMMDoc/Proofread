Process a sheet program

This workflow describes how to process a sheet program in TecZone Cut using punching machines and punch laser machines.

This procedure is based on the default program settings. Changed parameters can produce different results.

Create a sheet program

This section describes how to create a sheet program in HomeZone.
Requirement
HomeZone is opened.

  1. Select the Job category.

  2. Press New job in the toolbar.

  3. In the Job no. field, enter Laser_TL.

  4. Select Raw Material SS0M0250---.

  5. Press Add order.

  6. Find and select orders 100T8, 100T11, and 100TK5.

  7. If not all orders are displayed, press to reset the filter. Find and select 100T8, 100T11, and 100TK5.

    To select several orders, press and hold the Ctrl key.
    The sheet program can be created even if the order list displays a warning that the raw material is incompatible. The raw material entered for the job takes precedence over the raw material stored in the file.

  8. Press the OK button.

    All three orders are transferred to the order list.

    If no suitable laser technology table with rules is stored for the selected machine and raw material, copy the existing laser technology table, save it under a different name, and adjust it for the selected material. Switch to the Workplace category, select the machine, and press Configure.

  9. In the Machine field, select a 2D laser machine.

  10. Select at least one raw sheet size in the Raw Sheets field.

    If no quantity is specified, an unlimited sheet availability is assumed.

  11. Press the Open button.

    • TecZone Cut opens.

    • In the part overview bar, all three parts are marked with the symbol Underproduction.

    • The sheet layout is created in TecZone Cut in the following section.

Manage tool list

This section describes how to manage tool lists in TecZone Cut.

  1. Double-click the first sheet.

    • The sheet is shown in the single sheet view.

  2. Press the active tool button.

    • In the Tool dialog, the active tool can be selected and tool lists can be created or modified. The processing operations are created later with these tool lists.

  3. Select List tab.

  4. Press the List management button.

    The upper half of the dialog displays all tools stored in the database. The lower half displays the tools in the selected tool list.

  5. Press the New button.

  6. Enter Tutorial as the name for the new tool list.

  7. Select the following tools one after another in the list of all tools:

    • Round 5 mm

    • Round 20 mm

    • Square 30 mm

    • Square 50 mm

    • Rect 20 x 5 mm

    • Rect 37 x 5 mm

    • Rect 76.2 x 5 mm

      The new tool list is created. TruTops Boost automatically selects suitable tools from this list when processing operations are created. Other tools are required for cutting to pieces, while the round tools are not needed. The new list can be copied and modified.

      To find tools faster, restrict the list of all tools to a tool type using the selection field at the top right.

  1. Press the Copy…​ button.

  2. Select the New list: function and enter Cut to pieces as the name for the new tool list.

    The tool list "Cut to pieces" must be selected.

  1. In the field Tool list press ▼.

  2. In the tool list, select Cut to pieces.

  3. Select the tool Round 5 mm in the tool list.

  4. Press the Remove button. Confirm the removal of the tool from the list with Yes.

  5. Select the tool Round 20 mm in the tool list and remove it from the list.

  6. Add the tool Rect 40 x 6 mm to the tool list "Cut to pieces".

  7. Press the Return button.

  8. Close Tools.

Create a processing operation automatically

  • When processing operations are created automatically in the single sheet view, only the displayed sheet is processed.

  • When processing operations are created automatically in the sheet overview, all sheets are processed.

  1. Change to the sheet overview.

  2. Press tab Start > Technology, All ▼.

  3. Select the function Adjust…​.

  4. Activate the checkbox Punching and press ▼.

  5. Select Tools from list in the selection field.

    • With this setting, all tool lists stored in the database are available for the processing operations.

  6. Activate the checkbox Single hole and switch to the tool list "Tutorial" in the Tool list selection field.

  7. Activate the checkbox Cut to pieces: Inside and in the Tool list selection field, choose "Cut to pieces".

  8. Activate the checkbox Trimming and configure the following settings:

    • If Move layout autom. is inactive, activate the function.

    • Press Parameters.

  9. Select the Up to part edge function in the Cut off remainder strip field.

  10. Activate the Cut remainder strip to pieces checkbox in the Remove remainder strip field.

  11. Press the OK button.

  12. Activate the checkbox Outer notch and select the tool list "Tutorial".

  13. Activate the following checkboxes:

    • Corner

    • Element

    • Random notch

    • Twinline, and select the tool list "Tutorial" in the selection field

    • Contour

  14. In the top selection field, select All contours.

  15. In the bottom selection field, choose tool list "Tutorial".

  16. Activate the checkbox Part removal.

  17. Press the Save as …​ button.

  18. Enter Tutorial as the name for the new configuration and press OK.

  19. Press tab Start > Technology, All ▼.

  20. Select the tool list "Tutorial".

    • The processing operations are generated automatically in the order specified in the configuration.

    • All processing operations are created for the sheets.

    • The processing sequence must be optimized.

Optimize the processing sequence

  • During optimization, the processing of each sheet is checked for problems. If a problem occurs, a message appears under the sheet.

  • When processing is optimized in the single sheet view, only the displayed part is optimized.

  • When processing is optimized in the sheet overview, all sheets are optimized.

  1. If the sheet overview is displayed, double-click the first sheet and switch to the single sheet view.

  2. Press tab Start > Finish, Optimize…​.

  3. Confirm the Confirm list query with the Continue button.

  4. Activate the checkbox Short NC program in the Processing optimization dialog.

  5. Press the Continue button.

  6. Confirm Tool sequence with the OK button.

    • The processing sequence is optimized automatically.

    • The NC file can be generated, but automatically generated processing can damage finished parts.

    • The following sections describe how to delete and create processing operations manually.

Delete processing operations

  1. Press tab Start > Edit, Technology.

  2. Click on the processing to be removed.

    • The selected processing operation is highlighted.

  3. Press the Delete key.

    • The selected processing operation is removed.

    • Processing is created manually in the following section.

Create a processing operation manually

  1. When the TwinLine processing of the outer contour has been removed, press tab Start > Edit, Technology to create an outer contour processing operation manually.

  2. Select the active tool.

  3. To select the tool used to create the remaining TwinLine processing, right-click an existing TwinLine processing operation.

  4. Press the Activate tool button.

  5. Press the Process element with punching tool. tool guide.

  6. Click the contour for which the processing is to be created.

  7. When an inner contour processing operation has been removed, the operation is recreated by cutting scraps to pieces.

  8. To create the removed processing operation for the inner contour, press tab Technology > Create manually, Scrap.

  9. To select the tool used to process the remaining inner contours, right-click an existing processing operation.

  10. Press the Activate tool button.

  11. Press the Cut contour to pieces tool guide.

  12. Click the contour for which the processing is to be created.

    The execution sequence must be re-optimized after a processing operation is changed.

  13. Re-optimize the execution sequence.

The following section describes how to extend or shorten a processing operation directly on the sheet.

Adjust a processing operation

  1. Enlarge nibble processing.

  2. Press tab Start > Edit, Technology.

  3. Click on the processing required.

    • Two editing arrows appear at the processing operation for dragging it.

  4. Click the top editing arrow and keep the left mouse button pressed down.

  5. To extend or reduce nibble processing, move the editing arrow in the desired direction.

The sheet layout and processing operations are complete, and the execution sequence is optimized. The NC file is created and the sheet program is saved in the final section.

Generate and save the NC file

Pressing Create NC in the single sheet view generates an NC file for the displayed sheet. To create an NC file for all sheets, display the sheets in the sheet overview.
Requirement
All sheets will be displayed in the sheet overview.

  1. To switch to the sheet overview, press tab Start > View > All sheets.

  2. Press tab Start > Finish, Create NC.

    • The program creates the NC file for the current sheet program.

  3. To save the NC program, press .

  4. Close TecZone Cut.

    • The sheet program data is transferred to HomeZone and displayed in the Job category.

    • The NC file can be released and transferred to the machine.

Nesting parts with TwinLine distance

  • This workflow describes how to nest parts automatically with TwinLine distance.

  • TwinLine (= common cuts) is suitable for parts with simple outer contours.

  1. On the main functions toolbar, press Open order list in TecZone Open.

  2. Select a part.

  3. Select the Part tab.

  4. Select the TwinLine function in the Distance mode field.

  5. Press OK.

  6. Additional settings in the nesting parameters are required to create a sheet layout.

  7. Press tab Start > Sheet layout, Create sheet layouts ▼.

  8. In the main functions toolbar, select Parameters…​.

  9. Select the Part distances tab.

  10. In the Tool width field, enter 5 mm.

    • The TwinLine processing is created with a 5 mm-wide tool in the following step.

  11. Select the Options tab.

  12. In the Sheet margins - bottom field, enter 100 mm.

  13. Select the Technology tab.

  14. Select the Clamp dead strip function in the Consider clamps field.

  15. Press OK.

  16. Press tab Start > Sheet layout, Create sheet layouts.

    • The parts are placed automatically on sheets with TwinLine distance.

    • All sheet layouts are displayed in the sheet overview.
