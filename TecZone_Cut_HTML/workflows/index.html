Workflows

Workflows

This chapter compiles important standard processes and functions of TruTops Boost.

Performing the first steps in TruTops Boost

This tutorial describes all the steps that need to be taken when the program is started for the first time.

Skip steps that are not relevant.

Starting TruTops Boost

  • Starting TruTops Boost automatically starts the HomeZone control unit. TecZone Design, TecZone Laser, TecZone Bend and TecZone Cut are opened via HomeZone. Each TecZone opens in a separate window.

  • Closing HomeZone also ends TruTops Boost. Whether there is any data that has not been saved is checked for every TecZone. A corresponding message will be output.

  • If TecZone Design, TecZone Bend or TecZone Cut are closed manually, HomeZone remains open.

  1. To start TruTops Boost, double-click the TruTops Boost logo on the desktop.

    or

    In the menu, select Start > All programs > TRUMPF TruTops Boost. The welcome screen with videos and links is displayed.

  2. To hide the welcome screen, close the Welcome tab.

    or

    To show the welcome screen, press the button and select Show Welcome Screen.

  3. To show or hide the welcome screen permanently, activate or deactivate Show welcome screen upon start of application checkbox.

Defining general settings

  1. Define view.

  2. Select User interface language.

  3. Select System of units.

  4. Enter Elements in result list.

  5. Specifies the maximum number of elements that are to be displayed in the result list. The value must be between 50 and 1000. The higher the value, the longer the time required for loading.

  6. Define navigation.

  7. Standard navigation for links: Choose whether clicking a link should open a new tab.

  8. Standard navigation for buttons: Choose whether a new work step should be carried out in a new tab. This can lead to many open tabs in complex jobs.

  9. Default category: Choose the default category in which HomeZone should open - Part, Order, or Job.

  10. Define starting behavior.

  11. Start TecZone Design / Bend: When starting TruTops Boost automatically opens the corresponding TecZone when starting TruTops Boost.

    • Advantage: TecZone opens more quickly during initial access.

    • Disadvantage: Licenses and resources are used (approx. 500 MB for TecZone Design and TecZone Bend).

  12. During interactive opening: Opens the corresponding TecZone only if specifically activated.

    • Advantage: No licenses are used.

    • Disadvantage: Longer loading times.

  13. Restore last view when starting: Activate if the last used view should be displayed automatically when TruTops Boost is started.

  14. Determine Automatic update.

  15. Filter facets: Choose whether the defined filters should be automatically updated in HomeZone.

    The settings for the Designation and Documents sections apply across systems for all users.

  16. Define designations:

    • Standard prefix for the part no.: Default value for the prefix to the number for one or more parts if no part number is specified.

    • Standard prefix for the order no.: Default value for the prefix to the number for one or more orders if no order number is specified.

    • Standard prefix for the job no.: Default value for the prefix to the number for one or more jobs if no job number is specified.

    • Standard prefix for the job template no.: Default value for the prefix to the number for one or more job templates if no job template number is specified.

    • Standard prefix for the customer no.: Default value for the prefix to the number for one or more customers if no customer number is specified.

    • Select Language of the setup plans.

    • Select System of units for setup plans and import.

  17. Refers to setup plans only, not to NC files. Metric measurement units are entered in NC files.

    The language and unit settings only take effect after a restart.

  18. Press the OK button.

    • A material of your own is added to the materials management system in the next step.

    • If only TRUMPF standard materials are used, continue with the step Import bending machine in HomeZone or with Create 2D laser machine, punching machine or punch laser machine in HomeZone.

Adding your own material

During installation, standard TRUMPF materials are installed. The values of these materials have been optimized by TRUMPF and correspond to the most frequently used materials. An update will overwrite the standard materials. Modifications to standard materials are deleted. To define your own tools: Duplicate and adjust TRUMPF standard materials.

  1. Press the button in the column Categories in HomeZone. Select the category Material.

  2. Select the required material in the result list.

  3. Press the Duplicate button.

  4. Change Material ID.

  5. Enter the designation to be displayed for the material in the External name field.

  6. Change the parameters for the material.

    • For a new material, it is helpful to specify an LTT alias. Otherwise, there will be no suitable laser technology tables available for creating a sheet program.

    • In a later step, you will learn how to copy and adapt a laser technology table.

  7. Adjust raw material and raw sheets as required.

  8. Press Save.

  9. In HomeZone press Update master data.

    • The following steps describe how to import a bending machine and create a tool list with bending tools. If bending machines are not used, continue with Creating a 2D laser machine, punching machine or punch laser machine.

Creating a tool list for TecZone Design or TecZone Bend

Tool lists can only be created for press brake machines.

  1. Press Settings…​ at the top right.

  2. Select menu Bend.

  3. Press the Open button in the Tools area. The Tool management (die bending) opens.

  4. Press Tool lists ▼ and select <New…​>.

  5. Press Actions…​ and select Create tool list.

  6. Press the Rename tool list button.

  7. Enter the name of the tool list and confirm.

  8. To add a tool with all available segments to the tool list: Click on the area above a tool.

  9. To add a tool with selected segments to the tool list: Click on the tool.

  10. Click on the segment until the desired number is reached.

    Filter tools using the tool filter in the left area of the dialog according to type and shape.

  11. Press the Save button.

  12. To be able to select the newly created tool list in HomeZone: Update master data in HomeZone.

Creating a bending machine in HomeZone

If you are not using bending machines, continue with step 2D laser machine, punching machine, or punch laser machine in HomeZone.

  1. In HomeZone, press and select the Settings…​ menu.

  2. Press the New workplace ▼ button in the toolbar.

  3. Select New bending machine in the selection field.

  4. Enter parameters for the machine. If the selection field Machine is empty, press in HomeZone and select the Update master data button.

  5. Press Save in the toolbar.

  6. In order to modify the configuration of a press brake machine:

    • Press the Configure button in the Database area.

    • Modify Machine configuration parameters.

  • When working with press brake machines, the next step is to create tool lists that will be used in TecZone Design and TecZone Bend.

  • When working with panel benders: Step Define the default bending program.

Defining the default unfolding tool list

  • Tool lists can only be created for press brake machines.

  • The unfolding strategy selected here is automatically preset during import and taken into account during automatic calculation (BOOST). When a 2D geometry file is imported, a 3D model is automatically created if a tool list is stored for the unfolding.

  1. In HomeZone, press the button and select the Settings…​ menu.

  2. Select menu Design.

  3. On the Unfolding panel, select My tool list.

Define the default bending program

The default bending programs configured here are automatically preset in new parts. User-related or system-wide applicable default bending programs can be configured. System-wide applicable default bending programs are only preset for new parts if no user-related default bending programs are determined. Existing parts or orders are not affected by newly created default bending programs. During the import with subsequent calculation (BOOST), the default bending programs are automatically calculated.

  1. In HomeZone, press and select the Settings…​ menu.

  2. Select the Bend button.

  3. Add new default bending program:

    • To add a user-related bending program: In the My standard bending programs area, press the New button.

    • To add a system-wide applicable bending program: In the System standard bending programs area, press the New button.

  4. Modify Name.

  5. Select the Machine button.

  6. For press brake machines: select Tool List.

  7. Press the OK button.

  • If working exclusively with bending machines: End the tutorial at this point.

  • Following steps: The necessary initial work steps with a 2D laser machine, punching machine and punch-laser machine.

Creating a 2D laser machine, punching machine or punch laser machine

This section provides a short description of how to create a 2D laser machine, punching machine or punch laser machine for test purposes. To create a fully functioning production package, please observe the detailed information on the individual fields in the section: "Creating a cutting machine".

  1. In HomeZone select the Workplace category.

  2. Press the New workplace ▼ button in the toolbar.

  3. Select New cutting machine in the selection field.

  4. In the Name field, enter a unique name for the machine.

  5. If a laser machine or a punch laser machine has been selected: enter Maximum Laser Power.

  6. Press the Save button in the toolbar.

  7. In HomeZone press the Update master data button.

Defining the default cutting program

The default cutting programs configured here are automatically preset in new parts. User-related or system-wide applicable standard cutting programs can be configured. System-wide applicable default cutting programs are only preset for new parts if no user-related cutting bending programs are determined. Existing parts or orders are not affected by newly created default cutting programs.

  1. In HomeZone, press and select the Settings…​ menu.

  2. Select menu Cut.

  3. Add a new default cutting program:

    • To add a user-related cutting program: Press the New button in the My standard cutting programs section.

    • To add a system-wide applicable cutting program: Press the New button in the System standard cutting programs section.

  4. Modify Name.

  5. Select the Machine button.

  6. Select Angular Positions.

  7. Select Distance mode.

  8. Press the OK button.

  • When only 2D laser machines and TRUMPF standard material are used, the workflow ends at this point.

  • When a 2D laser machine or punch laser machine is used with custom material that has no LTT alias, an existing laser technology table must be copied and adjusted in the next step.

  • When only a punching machine is used, the next step can be skipped; continue with Create tool list for punching.

Copying and modifying laser technology tables

  • When custom material has been added in the materials management system without an LTT alias, an existing laser technology table must be copied and adapted for each raw material. Without this table, the material cannot be used.

  • Original TRUMPF laser technology tables are overwritten during every TruTops Boost update. Copies are retained.

  • Original TRUMPF laser technology tables cannot be modified. They can only be copied and saved under a different name.
Requirement
A 2D laser machine or punch laser machine is created.

  1. Switch to category Machine.

  2. Select the 2D laser machine or punch laser machine from the results list.

  3. In the Database area, press >_Configure_.

  4. Press the Laser button.

  5. Select technology tables (LTT).

    Search for technology tables with data similar to the new technology table.

  6. Mark the technology table.

  7. Press the OK button. The data are displayed in the mask head.

  8. Press the Copy button. Copy Laser Table is displayed. The name of the technology table will be extended by a leading K.

    A number can also be used as a name for the technology table. The table name must be at least 5000 in this case.

  9. Change the name of the technology table.

    Recommendation for alphanumeric technology tables: leave the K at the start of the table name.

  10. In the field Material ID, select the raw material for which the technology table is to be stored.

  11. Press the Copy button. A copy of the technology table will be made. The data of the copied technology table are displayed in the mask head.

    Make sure the copied technology table is displayed in the list.

  12. If the original technology table is displayed in the mask head, press Laser and select the technology table.

  13. To modify the header data of the technology table: Press Modify.

  14. Modify the header data of the technology table.

  15. Press the Modify button. Make sure the copied technology table is displayed in the list.

  16. If the original technology table is displayed in the mask head, press Laser and select the technology table.

  17. To modify the parameters of the copied technology table:

    • Press Next button.

    • Modify the parameters.

  18. To save changes: Press the Modify.

  19. To close the dialog, press the Exit button.

  20. In HomeZone press the Update master data button.

If you are only using 2D laser machines, you can end the tutorial at this point.

Creating a tool list for punching

  • When tool lists already exist, this step can be skipped. The following step describes how to enable or disable all tools in a tool list.

  • Tool lists for punching must be created in TecZone Cut. In order for TecZone Cut to be opened, at least one part must be imported into HomeZone.
Requirement
A 2D laser machine or punch laser machine is created.

  1. Switch to category Part.

  2. Press the Import button.

  3. Select part and import in HomeZone.

  4. Cutting Programs Press the New button.

  5. Select a punching machine or punch laser machine in the Machine field.

  6. Press the Open button. TecZone Cut opens up.

  7. On the main functions toolbar, next to active tool, press the button.

    • In the Tools dialog, you can normally select the active tool. However, you can also use this dialog to create and modify tool lists in TecZone Cut.

  8. Select List tab.

  9. Press the List management button.

    • All tools stored in the database are displayed in the upper part of this dialog. The bottom half shows all tools contained in the selected tool list.

  10. Press the New button.

  11. Enter name for new tool list.

  12. Select the tools that are to be added to the tool list one after the other from the upper list field.

    • The selected tools are inserted in the lower list field.

      In order to find tools quicker, restrict the selection in the list with all tools to a particular tool type. Use the top right selection field to do so.

  13. Press the Return button.

  14. To close the tool database: Press Cancel.

Deleting or disabling all tools of a punching tool list

  • When the tool management system is already open, processing can start with step 8.

  • Tool lists for punching must be processed in TecZone Cut. In order for Cut to be opened, at least one part must be imported into HomeZone.
Requirement
A 2D laser machine or punch laser machine is created.

  1. Switch to category Part.

  2. Press Import.

  3. Select part.

  4. Press the Open button.

  5. Cutting Programs Press the New button.

  6. Select a punching machine or punch laser machine in the Machine field.

  7. Press Open. TecZone Cut opens up.

  8. On the main functions toolbar, press .

    • In the Tools dialog, you would normally select the active tool. However, you can also use this dialog to create and modify tool lists in TecZone Cut.

  9. Select List tab.

  10. Press the List management button.

    • All tools stored in the database are displayed in the upper part of this dialog. The bottom half shows all tools contained in the selected tool list.

  11. Select the tool list for which punching tools are to be disabled or deleted.

  12. If the punching tools are to be deleted: Press Delete all.

  13. If the punching tools are to be disabled: Press Disable all.

    • Disabled tools can no longer be selected in the tool management system.

  14. To close the tool database: Press Return.

  15. Press the Cancel button.
