Place a part

  • This section describes manually placing a part on the sheet.

  • Take parts sensing into account.
Requirement
The sheet is shown in the single sheet view.

  1. Create a new job in HomeZone.

  2. Open the sheet program for the job in TecZone Cut.

  3. Place an unprocessed part on the sheet:

    • Select the desired part in the part overview bar and drag it onto the sheet, keeping the mouse button pressed.

  4. Place a processed part on the sheet:

    The button will only be shown if cutting programs are available.

    • In the part overview bar, press the button.

  5. Select the processed part with the desired angular position and drag it onto the sheet, keeping the mouse button pressed.

  6. If necessary, process the sheet layout.

Activating parts sensing

The permissible part position can be checked when laying out a sheet and during free movement and copying of parts. Here, the parts can only be placed so close to other parts or at the sheet margin as the set parameters allow.

The Observe sheet margin function monitors the distance to the sheet margins. The sheet margins are configured in the nesting parameters.

The Observe parts function monitors the distance between the parts. The minimum distance between the parts depends on the selected distance mode and the values set in the nesting parameters.

The functions are active if the corresponding button is framed in blue.

  1. In the Edit tab, press the Sheet layout button.

  2. To activate the Observe sheet margin function: press .

  3. To activate the Observe parts function: press .

  4. To set the distance to the sheet margin:

  5. In the Start >_Sheet layout_ tab, press the Create sheet layouts button.

  6. Select Parameters…​.

  7. Select Options and define the distance.

  8. To define the parts distances for the selected distance mode:

    • In the Start > Sheet layout tab, press the Create sheet layouts button.

    • Select Parameters…​.

    • Select Part distances and define values.

Moving a part

Parts on a sheet can either be moved freely, vertically or horizontally.

A part can be moved exactly using the reference point and the anchor point. The arrows for moving the part at the anchor point. The reference point only appears if a part is moved using the arrows. The distance is measured from the reference point to the anchor point of the two arrows.

  • A defined distance can be entered, by which a part should be moved.

  • A defined distance to a contour or edge can be established. The reference point and anchor point can be moved. Both points scale automatically once the respective point is drawn onto an edge or contour.

Example: Moving a part

The Boost Tool Sheet layout must be active for this to work.

  1. In the Start > Edit tab, press the Sheet layout button.

  2. If parts sensing is inactive: Activate parts sensing.

  3. Select the desired part.

    • To select several parts, press and hold the Ctrl key.

    • Draw a selection frame around the desired parts. Only parts that are completely inside the selection frame are selected.

  4. To move a part freely: move the part with the left mouse button pressed.

    • The part is placed where the mouse button is released.

  5. To establish a defined distance to an edge or contour of the selected part: drag the anchor point to the edge or contour.

  6. To move a part horizontally: Click on the red arrow and move the part in the desired direction with the mouse button pressed.

  7. To move a part vertically: Click on the green arrow and move the part in the desired direction with the mouse button pressed.

    The reference point appears as soon as the part is moved vertically or horizontally.

  8. To establish a defined distance to an edge or contour of another part or to the sheet margin: drag the reference point to the edge or contour.

    The input field will appear as soon as the part has been moved horizontally or vertically.

  9. To move the selected part by a defined distance: Enter the value by which the part should be moved in the input field.

  10. Confirm the input with the Enter key.

Rotating a part

Parts can be rotated freely onto a sheet.

The Boost Tool Sheet layout must be active for this to work.
Example: Rotating a part

Rotate around the anchor point

This section describes rotating a part around the anchor point.

  1. In the Start > Edit tab, press the Sheet layout button.

  2. Select the desired part.

    • To select several parts, press and hold the Ctrl key.

      Only parts that are completely inside the selection frame are selected.

    • Draw a selection frame around the desired parts.

    • The anchor point is displayed. The anchor point is the pivot of the processing job. The anchor point can be moved freely.

  3. To move the anchor point: Hold down the left mouse button and drag the blue arrow in the desired direction.

    • The angle that the part is rotated is displayed.

  • The processing job cannot be moved while it is rotated.

  • The further away the mouse pointer is from the pivot, the more precisely the processing job can be rotated.

  1. To rotate the part by 90Â°: Move the mouse pointer close to the pivot point.

  2. To rotate the part in 0.1Â° increments: Move the mouse pointer far away from the pivot point.

  3. To enter an angle of rotation:

    • Press Tab key or click in the input field.

    • Enter the number of degrees.

    • Press Enter key.

Rotating a part with the mouse wheel

  1. In the Start > Edit tab, press the Sheet layout button.

  2. Select the desired part.

    • To select several parts, press and hold the Ctrl key.

    • Draw a selection frame around the desired parts. Only parts that are completely inside the selection frame are selected.

      The part can be freely moved while it is rotated.

  3. Move part freely: Press and hold the left mouse button.

    The part is rotated by the angle increment specified in the system rules variable IncrementForRotationByUserInteraction.

  4. Press and hold the Shift key and turn the mouse wheel.

    • The part is rotated by the specified angle increment.

  5. Press and hold the Shift and Ctrl key and turn the mouse wheel.

    • The part is rotated by 10 % of the specified angle increment.

    • The part is rotated around the point where the mouse pointer is.

  6. Press the Shift key and turn the mouse wheel.

    • The part is rotated around the point where the mouse pointer is.

Copying a part

Parts on a sheet can either be copied freely or vertically/horizontally. Alternatively, parts can be copied with the key combination Ctrl+C. Parts can be inserted on the same sheet, on a different sheet of the same sheet program or on a sheet of another sheet program. Copied parts will be inserted at the position of the original parts.

  • The Boost Tool Sheet layout must be active for this to work.

  • TecZone Cut does not check whether parts already exist at the position where the copied parts are to be inserted. In this case, copied parts must be moved manually.

  1. In the Start > Edit tab, press the Sheet layout button.

  2. Select the desired part.

    • To select multiple parts, press and hold Strg or Ctrl.

      Only parts that are completely inside the selection frame are selected.

    • Draw a selection frame around the desired parts.

  3. Freely copy part: Press and hold Ctrl and move the part.

    • A copy is made of the selected parts and is moved.

  4. Copy part horizontally: Press and hold Ctrl and drag the red arrow.

  5. Copy part vertically: Press and hold Ctrl and drag the green arrow.

  6. To copy the part: press Ctrl+C.

  7. To insert the part: press Ctrl+V.

    • The copied part is inserted at the original part’s position.

  8. To move the part manually: Move the part with the mouse.

Flipping a part interactively

Parts are mirrored at the perpendicular bisector of the overall selection.

  • For punching machines, punch laser machines and TruLaser Center 7030 (L26), the processings already created are applied after mirroring, as far as possible.

  • For the 2D laser machines excluding TruLaser Center 7030 (L26), the processings are re-calculated at the part after flipping.

  • Mirrored parts are registered under the genuine part.

  1. In the Start > Edit tab, press the Sheet layout button.

  2. Select the desired part.

  3. Draw a selection frame around the desired parts.

  4. Open the mini toolbar with the right mouse button and press the Mirror parts button.

Processing parts grids

If the parts on a sheet are selected, the system automatically detects whether the parts form a uniform grid. Each grid cell is identified with a cross. Additional functions are available for processing the grid. Various sizing tools are displayed around the grid area.

  • The parts grid can be processed as follows:

    • Change the number of parts in the grid.

    • Modify the parts distance in the grid.

  • If the parts distance in the grid is changed, the following distances are displayed:

    • Distance of the enclosing rectangles of adjacent parts

    • Distance from the edge of the grid to the rectangle around the 2nd part

    • Grid size

The values can be changed if the exact distance is to be established. If the size of the grid is changed, the parts distances are adjusted automatically.

The parts distance can be increased or decreased. Depending on where the grid is handled, the parts distance can be changed up, down, left or right.

Example: Modifying the parts distance in the grid

  • When only one cross is displayed in the middle for several selected parts, the parts are not distributed evenly in the grid. In this case, the grid cannot be processed.

  • A part grid is not saved. The part grid is detected afresh each time parts are selected.

  1. In the Start > Edit tab, press the Sheet layout button.

  2. Create a selection frame around all parts that belong to the grid.

    • Each grid cell is identified with a cross.

  3. To increase the number of parts line by line or column by column: Select and drag the grid frame outwards.

  4. To reduce the number of parts line by line or column by column: select and drag the grid frame inwards.

  5. To modify the parts distance: select and drag the grid frame inward or outward.

    • The distances in the grid are displayed.

    • If parts sensing is active and minimum distances are maintained: Parts are moved to the new target position.

    • If parts sensing is active and minimum distances are not maintained: Parts are moved back to their starting position.

    • If parts sensing is inactive: Parts are moved to the new target position. Distances are not checked. No message is displayed if the minimum distances are not met.

  6. To establish an exact distance: enter the desired value in one of the fields.

  7. Confirm the input with the Enter key.

Deleting a part

Parts can be deleted from a sheet with the Delete key.

Alternatively, parts can be deleted using the Boost Tool Select button on the mini toolbar.

The Boost Tool Sheet layout must be active for this to work.

  1. In the Start > Edit tab, press the Sheet layout button.

  2. Select the desired part.

    • To select several parts, press and hold the Ctrl key.

    • Draw a selection frame around the desired parts. Only parts that are completely inside the selection frame are selected.

  3. Press the Delete key.

  4. In the mini toolbar, press the Delete marked parts button.

To remove parts of a grid row by row or column by column: Reduce the number of parts in the part grid.

Replacing a part

Parts on the sheet can be replaced by a part with the current date of modification. This new part must be on the sheet.

The Replace parameters dialog appears automatically as soon as Replace part is pressed.

Replace parameters
Field Description

Search parts with identical angular position

If a part is selected for replacement, all other parts with the same angular position are selected.

Replace processings

The processings of the new part are transferred.

If the new part does not have any processings, those of the genuine part are retained.

  • This function is available for punching machines, punch laser machines and for TruLaser Center 7030 (L26).

  • Varying outside dimensions can lead to geometry violations or the sheet section is not used optimally. The webs between the parts may be wider than required because the webs are not adapted to the new outside dimensions of the parts.

  1. Press tab Nesting > Sheet layout, button Replace part.

    • The Replace parameters dialog opens.

  2. To select and replace parts with the same angular position at the same time: activate checkbox Search parts with identical angular position.

  3. To transfer the processing of the new part: activate the Replace processings checkbox.

  4. Select the part which is to replace other parts.

    • Select the parts to be replaced.

  5. Press the OK button.

Updating a part

In the part overview bar, the button shows whether changes to the design of a part have been made later on.

To update the design of a part: Press the button in the parts overview bar.

If the cut geometry of a part is already used in a sheet layout, three options are available:

  • Remove all: All associated parts are removed from all sheets. To add new parts to the sheet layout: Re-nesting.

  • Replace all: All associated parts are replaced by the new part geometry. Any existing processing operations to the old parts are not applied. No check as to whether collisions with the sheet or part geometry can occur.

  • Replace: Check whether collisions with the sheet or part geometry can occur. Processing operations of adjacent parts such as approach flags are not taken into account during this test.

    • If collisions occur: the corresponding parts are removed from the sheet. To add removed parts to the sheet layout again: Re-nesting.

    • If no collisions occur: the old part is replaced by the updated part. Existing processing operations to the old parts are not adopted.

Update and apply processing

This section describes updating a part and applying processing operations.

If the cut geometry of a part is already used in a sheet layout, but subsequently changed in TecZone Design, the existing processing can be applied in the sheet layout using the following steps:

  1. Open the sheet program in TecZone Cut.

  2. A part to be changed in TecZone Design should be saved as Single part cutting program.

  3. Open the part geometry in TecZone Design. Adjust and save the geometry.

  4. Updating the part in the cutting program.

  5. Completed contours via Processing unprocessed contours. Save cutting program.

  6. In HomeZone in the job detail area, adjust the job-specific specifications of the part:

    • In the Part tab, set the Cutting Program parameter to "Automatic".

    • Select the desired cutting program.

  7. Open the sheet program in TecZone Cut.

  8. Update the design of the part on the sheets.

  9. Transferring processing of the updated cutting program onto the sheets:

  10. In the View tab, press the All parts button.

  11. At the corresponding part checkbox activate Apply processings.

  12. In the View tab, press the All sheets button.

Selecting overlapping parts

  1. In the Start > Edit tab, press the Select button.

  2. Click on the parts lying on top of one another.

  3. Press and hold the Ctrl key and turn the mouse wheel.

    • The selected part is highlighted in color.

  4. Click on the selected part and process.

TwinLine distance

In case of common cuts (TwinLine), the contours of contiguous parts are cut at the same time. I.e., the contours are processed with one cut. This processing strategy ensures that there is no remainder sheet between the parts and therefore no scrap skeleton.

When parts are to be cut using common cuts, the clearance between the parts must match the size of the tool. For 2D laser machines, this is the kerf from the laser technology table. For punching machines and punch laser machines, the clearance between the parts must match the tool width which is to be used for the TwinLine processing.

This distance is set in each of the nesting parameters > Part distances in the Tool width field.

For 2D laser machines and punch laser machines, the kerf of the laser is entered as the tool size by default. The kerf is determined automatically based on the laser technology table selected for the sheet program. The tool size can be changed later. If the changed value is saved, it is retained until a new laser technology table is selected.

For each part which is to be placed at TwinLine distance, the TwinLine must be defined.

TwinLine contours are processed with the active tool after nesting.

  • For punching, the following tools are permitted for TwinLine processing:

    • Square

    • Square with radius

    • Rectangle

    • Rectangle with radius

    • Oblong hole

    • A few special tools

  • This function is not available for TruLaser Center 7030 (L26).

  • Parts distance and clearance mode must be set before the automatic creation of the sheet layout.

  • When creating a sheet layout manually, parts sensing must be active to ensure that the TwinLine clearance is taken into account.

  1. Open the parts dialog box.

  2. Select the parts that are to be placed at TwinLine distance.

  3. To select several parts, press and hold the Ctrl key.

  4. To select all parts: Press Ctrl+A.

  5. Select the Distance module TwinLine button.

  6. Press the OK button.

  7. To open the nesting parameters: In the tab Start > Sheet layout, press button Create sheet layouts â–¼.

  8. Select the Parameters…​ button.

  9. Select Part distances.

  10. Enter the size of the tool with which TwinLine processing is to be executed in the Tool width field.

  11. For 2D laser machines and punch laser machines, the kerf of the laser is entered by default.

  12. If processing is executed with a punching tool: enter the size of the slitting tool.

  13. Press the OK button.

  14. If a manual sheet layout: activate parts sensing.

  15. For an automatic sheet layout: press button Create sheet layouts.

  16. To create a TwinLine processing operation with the active tool: In the tab Start > Technology press button TwinLine.

Aligning parts

The Align function can be used to align parts on the sheet as follows.

Alignment Description

Distribution

This function does not support scrap skeletons and remainder sheets.

Parts are distributed on the sheet in the X and Y directions. The distances between the parts are increased.

Possible collisions are avoided and the scrap skeleton becomes more stable.

Distribute horizontally

This function does not support scrap skeletons and remainder sheets.

Parts are distributed on the sheet in the X direction.

Distribute vertically

This function does not support scrap skeletons and remainder sheets.

Parts are distributed on the sheet in the Y direction.

Center horizontally

Parts are centered horizontally on the sheet.

All selected parts are treated as one large part.

Center vertically

Parts are centered vertically on the sheet.

All selected parts are treated as one large part.

To the left

Parts are moved as far as possible into the left half of the sheet.

All selected parts are treated as one large part.

To the right

Parts are moved as far as possible into the right half of the sheet.

All selected parts are treated as one large part.

Upward

Parts are moved as far as possible into the top half of the sheet.

All selected parts are treated as one large part.

Down

Parts are moved as far as possible into the bottom half of the sheet.

All selected parts are treated as one large part.
The minimum distance between the two parts is taken into account during the alignment.

  1. Select part.

    • Select several parts individually.

    • Draw a selection frame around parts.

  2. In the tab Nesting > Sheet layout, press button Align â–¼.

  3. Sheet layout according to Distribution is uneven: Press the Distribute horizontally button.

    • Press the Distribute vertically button.
