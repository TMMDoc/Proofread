Change the order list

In HomeZone, parts can be added to or removed from a job’s order list.

If the job’s sheet program is open in TecZone Cut, the order list can be processed without closing TecZone Cut. After the changed order list is saved in HomeZone, the changes are applied in TecZone Cut.

Parts can be imported directly in TecZone Cut. The associated orders are not created automatically in HomeZone.

Some parts data can be processed directly in TecZone Cut.

Order list: Parameters

Part name: The part name is set in the parts list in HomeZone.

Order number: The order number is set in the order list in HomeZone.

Customer: The customer name is set in HomeZone in the order list.

Subsequent workstation: The subsequent workstation is set in the parts list or the order list in HomeZone.

Sample parts: Number of parts which are to be created as sample parts. Sample parts can be used to check the quality of cut parts at the start of production. The sample parts are placed on the sheet such that all sample parts lie immediately next to each other and can be examined from the outside.

As standard, no sample parts are produced.

Number of pieces: Max, Min, Actual: Quantity, number of times a part is to be placed on the sheet. The quantity is set in the order list in HomeZone.

Angular position: If no cutting program has yet been created for the part, the angular position of the part can be adjusted with this parameter. The desired angular positions can be selected from a selection field or entered directly. The following details are possible:

  • Enter the allowed angle directly. Separate multiple entries with ;. The part is only placed on the sheet in the angular positions entered in the field. Example: To place the parts on the sheet at angles of 15°, 45° and 60°: enter 15;45;60.

  • Enter the allowed angle range. Separate multiple entries with ;. The part can be placed on the sheet in the angular positions which lie in the entered range. Example: To place parts on the sheet at angles between 45° and 100° and between 120° and 160°: enter 45-100;120-160.

  • Enter incremental angle by which the parts may be rotated during automatic nesting. The finer the incremental angle, the greater the calculation effort. Example: To assign the fixed angle of rotation 45° to a part: Enter 45…​. For automatic nesting, the angular positions 0°, 45°, 90°, 135°, …​, 315° are taken into account.

For automatic nesting, 90° is set by default.

Consider rolling direction: Activate this option when the rolling direction must be considered. For sheets with rolling direction = Y, the specified angular positions are rotated by 90°.

  • The following angular positions are possible:

    • 0°

    • 0°;180°

    • 90°;270°

The rolling direction can be defined at any edge in TecZone Design. When the geometry is saved, the part is rotated to align with the X rolling direction. TecZone Cut therefore receives the part in the X rolling direction.

Distance mode: Depending on the distance mode, different parts distances are allowed. For automatic nesting, Grid processing is set by default. The following entries are offered:

  • Grid processing - A web remains between the parts during executing. A scrap skeleton is formed. The clearance between the parts is at least the web width + 2 times the tool width. Both values are entered in the nesting parameters. This clearance can be bigger within the range of the nesting accuracy that was configured. Grid processing is not suitable for TwinLine processing.

  • TwinLine - Adjacent parts have a common cut. The clearance between the parts exactly matches the tool size entered in the nesting parameters. No scrap skeleton is formed. If a TwinLine clearance is not yet possible, the clearance to the grid machining or the web-free processing is used.

  • Web-free processing - The clearance between the parts results from the tool size and a supplemental clearance. Web-free processing is only possible for punching.

The parts distances associated with the different modes are defined in the nesting parameters.

Ignore processings: Activate this option to ignore processing operations.

Use TwinLine blocks: When using TwinLine, it is possible to enter the length in the X and Y directions after which a larger distance should be inserted. A web is formed between the blocks. The TwinLine clearance is used within the blocks.

Priority: The lower the number, the higher the priority of the part. A high priority means that the part must be placed on the sheet first. Parts with a lower priority are placed on subsequent sheets or in gaps. The default value for each part is 5.

  • Define the priority:

    • Adjust with the slider.

    • Enter the number directly.

Open, process order list

The following steps describe how to open and process an order list in TecZone Cut.

  1. On the main functions toolbar, press Open order list in TecZoneOpen.

  2. Press the F2 function key.

  3. Select one or more parts in the order list.

  4. To select several parts, press and hold the Ctrl key.

  5. Select Part tab.

  6. Enter the parameters.

  7. Press the OK button.

Adding a part or order

New parts or orders can be added to a job via HomeZone. TecZone Cut does not have to be closed for this.

  1. On the main functions toolbar, press Change order list in HomeZone.

    • HomeZone is displayed in the foreground. The current job is open.

  2. To add orders:

    • In HomeZone, in the Order List field, press Add order.

    • The Select Orders dialog opens.

    • Filter orders using the search option.

    • Select one or more orders and press OK.

    • The selected orders are transferred to the order list.

  3. To add parts:

    • In HomeZone, in the Order List field, press Add part.

    • The Select parts dialog opens.

    • Filter the parts using the Search option.

    • Select one or more parts and press OK.

    • The selected parts are transferred to the order list.

  4. Press the Save button.

    • TecZone Cut adopts the new parts in the part overview bar.

Importing a part

2D geometries (*.geo, *.dxf and *.dwg) can be directly added to a sheet program which has been opened in TecZone Cut. Several parts can be added simultaneously by means of drag-and-drop.

  • File name of the 2D geometry: Umlauts and special characters are not permitted. Spaces " ", underscores "_", hyphens "-" and dots "." are permitted.. If special characters such as a comma are required, the system rules variable
    ReplaceUnneccessaryCharactersFromFileName
    must be set to "0".

  • New parts are created automatically in HomeZone in the Part category. If an identical part already exists, the existing part is used.

  • For new parts, orders will not be created automatically in HomeZone in the Order category. For this reason these parts will not be added to the order list for the job in HomeZone.

  • New parts, for which there are no orders in HomeZone, will automatically be removed from the job when TecZone Cut is closed if the parts are not used on any sheet.

Import via selection dialog

This is an alternative to importing a part by drag-and-drop.

  1. In the Start >_Sheet layout_ tab, press the Import part…​ button.

    • The file-selection dialog opens.

  2. Select 2D file (*.geo, *.dxf or *.dwg). Only one file can be imported at a time.

    • The part is added to the part overview bar and order list in TecZone Cut.

Import using drag-and-drop

  1. Drag a 2D file (*.geo, *.dxf or *.dwg) from Windows Explorer and drop it into the part overview bar. To select several files, press and hold the Ctrl key.

    • The part is added to the order list in TecZone Cut.

Removing a part

Parts can be added to or removed from a job’s order list via HomeZone. TecZone Cut does not need to be closed for this.

  1. On the main functions toolbar, press Change order list in HomeZone.

    • HomeZone is displayed in the foreground. The current job is open.

  2. In the order list, select one or more parts which are to be removed.

  3. To select several parts, press and hold the Ctrl key.

  4. In HomeZone, in the field Order List, press button Remove.

    • The selected parts are removed from the order list.

  5. Press the Save button.

    • If the removed part has not been placed on a sheet, it no longer appears in the part overview bar in TecZone Cut.

    • If the removed part has already been placed on a sheet, the required quantity is reduced to 0 in the part overview bar in TecZone Cut. The part is not deleted from the sheet automatically.
