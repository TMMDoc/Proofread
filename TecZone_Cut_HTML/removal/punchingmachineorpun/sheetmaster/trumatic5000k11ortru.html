TruMatic 5000 (K11) or TruPunch 3000 (S20) with SheetMaster (AK09)

TruMatic 5000 (K11) or TruPunch 3000 (S20) with SheetMaster (AK09)

The automation components for the machines are the SheetMaster and the GripMaster. In combination, these components enable automated loading of raw sheets and unloading of good parts, scrap parts and scrap skeletons.

Machine Overview

  1. SheetMaster with gripper unit for loading sheets and unloading good parts. The linear drives enable this component to move in the X and Z directions. The two gripper beams of the gripper unit can also move in the Y direction.

  2. Basic machine TruMatic 5000 (K11)

  3. GripMaster for unloading scrap skeleton

Calculation of the gripping unit position

When calculating the automatic or manual SheetMaster removal, TruTops Boost checks two positioning options in this order:

  • The gripper unit can be positioned outside the obstructions of the punching head or repositioning device. Removal can be carried out without the punching head having to move away together with the repositioning device (if present). In this case, removal with separation after suction is possible.

  • The contours of the gripper unit and punching head or repositioning device overlap. Before the gripper unit can be positioned for removal, the part is completely cut free and the punching head or repositioning device is retracted. Removal with separation after suction is therefore not possible.

Positioning of the gripper unit outside the obstructions of the punching head and repositioning device

Positioning of the gripper unit, where there is an overlap with the obstructions of the punching head and repositioning device

The system rules variable GrippingUnitPosOutPunchHeadObstruction specifies whether the SheetMaster should only create removals outside or inside the obstructions of the punching head and repositioning device. Default setting is "0": Removals are created within the obstructions.

In the following cases, removal with the SheetMaster (AK09) is not possible:

  • The part weight exceeds the carrying capacity of the SheetMaster.

  • The part protrudes too far beyond the obstruction of the SheetMaster. In this case, a corresponding message is displayed during optimization. If necessary, the removal can be adjusted manually to comply with the limit values for the overhang.

Programming the SheetMaster (AK09) is described in the "Workflow" chapter: Configuring and programming the TruMatic 5000 (K11) with SheetMaster (AK09).
Requirement

  • SheetMaster (AK09) and GripMaster (AK09) are configured in Data Manager Cut.

  • Single sheet mode is active.

Automatically creating SheetMaster removal

With the SheetMaster, automatic calculation for removal is available for both laser processing and punching.

During automatic calculation, processed inner contours are taken from the SheetMaster but not created as scrap parts. Scrap items that are treated as such during palletizing can only be created manually (see Creating scrap part removal manually).

The parameters for the automatic calculation can be adjusted in Data Manager Cut: Select > File > Adjust machine…​. In Data Manager Cut, select > Process rule > Part removal and define the corresponding parameters for Gripping Unit Gutteil Laser or Gripping Unit Gutteil Punch.

  1. In the tab Technology > Create automatically open button All [active configuration] with â–¼ and select TruMatic or TruMatic Punch Only.

    • The calculation is performed. A window with the results opens.

    • The parts are marked with the symbol for the SheetMaster.

Creating good parts removal manually

  1. To adjust the speed and acceleration of the SheetMaster: In the tab Removal > Gripper unit, press the Change gripping unit parameters. button.

  2. Modify the parameters:

    Field Description

    Speed:

    SheetMaster speed

    Acceleration:

    Acceleration of the SheetMaster

    Acceleration from scrap skeleton:

    Acceleration of the SheetMaster if the suctioned part is lifted from the scrap skeleton

  3. In the tab Removal > Gripper unit, press button Set.

    • The tool guides are displayed.

  4. Select tool guide CREATE, button Create finished part removal and select contour processing.

    • The SheetMaster removal is set at the end of the processing line.

    • The gripping unit and the punching head or the repositioning device are displayed.

    • The Modify function is active or Select tool help CREATE, button Move approaching and create finished part removal and select a new starting point for laser processing.

    • The laser processing is adapted to the new approach position.

    • The SheetMaster removal is set to the selected position.

    • The gripping unit and the punching head or the repositioning device are displayed.

    • The Modify function is active.

  1. If necessary Change SheetMaster removal.

  2. To configure the removal of good parts: Create removal manually with parameters.

Creating scrap part removal manually

  1. To adjust the speed and acceleration of the SheetMaster: In the tab Removal > Gripper unit, press the Change gripping unit parameters. button.

  2. Modify the parameters:

    Field Description

    Speed:

    SheetMaster speed

    Acceleration:

    Acceleration of the SheetMaster

  3. In the Removal > Gripper unit tab, press the Waste part button or Tool guide CREATE SCRAP PART, press the Create scrap part removal button.

    or in tab Removal > press Gripper unit, Set (parameters).

    • The dialog Removal with gripping unit opens.

  1. Modify the parameters:

Field title Field Description

What do you want to remove?

Finished part

Finished parts are removed.

What do you want to remove?

Scrap

Scrap parts are removed.

Parameters

Open clamps

Clamps are opened if the part or sheet is removed with SheetMaster. If a sheet is to be removed, the clamps are automatically opened.

Each clamp can be selected individually on machines with clamps that can be opened individually.

Parameters

Separate after suction

The part is only fully released after suction has been applied to it by the SheetMaster. This is not possible if one or more clamps are opened

Only available for punching

A punching tool must be activated.

The punching head and, if present, the repositioning device must not be located under the SheetMaster removal.

Punching mode for last stroke

remains

The separation stroke is carried out in the current punching mode.

Punching mode for last stroke

Normal

The separation stroke is executed without presser foot and without delay.

Punching mode for last stroke

Delayed

The separation stroke is executed after a certain time interval (delayed) after the position is reached.

Application: For processing operations far from the center of gravity or when the sheet has to be swung out.

Punching mode for last stroke

Presser foot

In the case of the separation stroke, the sheet is pressed hydraulically against the die using the presser foot.

This punching mode is practical in the following cases:

  • If the sheet can warp

  • If punched holes are very close to each other

  • If thin sheets are processed

Punching mode for last stroke

Delayed+Presser foot

The separation stroke is executed after a certain time interval (delayed) after the position is reached. The sheet is pressed hydraulically against the die with the presser foot.

    • The gripping unit and the punching head or the repositioning device are displayed.

  3. If necessary Change SheetMaster removal.
