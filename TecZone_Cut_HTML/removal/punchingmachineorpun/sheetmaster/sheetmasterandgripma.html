SheetMaster and GripMaster

The SheetMaster is used for automatic loading and unloading of sheets and finished parts. GripMaster enables process-reliable unloading of scrap skeletons and remainder strips.

The following symbol indicates that parts or sheets were removed with SheetMaster: .

Activate the NcWriteScrapGeometry machine rule variable if the geometric data of the scrap part is to be written to the master file. Remainder sheets disposed of with the SheetMaster (scrap or scrap skeleton with suction cup) are displayed on the machine as a graphic.

Remove with lift parameters

Remove what?
Field Description

Finished part

Remove good part with SheetMaster.

Scrap

Remove scrap part with SheetMaster.

Skeleton with suction cups

Remove the microjoint sheet or scrap skeleton with SheetMaster.
Open clamps and slitting
Field Description

Open clamps

Clamps are opened if the part or sheet is removed with SheetMaster. If a sheet is to be removed, the clamps are automatically opened.

Each clamp can be selected individually on machines with clamps that can be opened individually.

Separate after suction

The part is only released completely after suction has been applied to it by the SheetMaster.

Not possible if one or more clamps are opened

Separate after deposit

The part is only completely cut free once SheetMaster has been set down on the part. The part is not attached by suction yet.

Not possible if one or more clamps are opened
Punching mode for last stroke
Field Description

remains

The separation stroke is carried out in the current punching mode.

Normal

The separation stroke is executed without presser foot and without delay.

Delayed

The separation stroke is executed after a certain time interval (delayed) after the position is reached.

  • Application:

  • Processing operations are far from the center of gravity.

  • When the sheet has to swing out

Presser foot

In the case of the separation stroke, the sheet is pressed hydraulically against the die using the presser foot.

  • This punching mode is practical in the following cases:

  • If the sheet can warp

  • If punched holes are very close to each other

  • If thin sheets are processed

Delayed+Presser foot

The separation stroke is executed after a certain time interval (delayed) after the position is reached. The sheet is pressed hydraulically against the die with the presser foot.

  • Maintain the settings for sequential multiple part removal for all removals:

  • Only relevant if the selected SheetMaster supports sequential multiple part removal

  • If the option is active, the selected settings are used for all following individual removals.

Remove parts with SheetMaster

SheetMaster removes good parts, scrap parts and the scrap skeleton.

  • Removal with SheetMaster is configured.

  • Single sheet mode is activated.

  • The part to be removed must have been completely processed.

Activate or deactivate carrier suction cups

Carrier suction cups of a suction cup group cannot be activated or deactivated individually. The suction cup group is always activated or deactivated as a whole.

  1. Tool guide SUCTION CUP, press the Adapt suction cups button.

  2. Select the carrier suction cups to be activated or deactivated. To do this, move the mouse pointer to the edge and click.

    • Active carrier suction cups are shown in magenta color. Deactivated carrier suction cups are shown in blue.

Adjust the position of the SheetMaster: Adapt lift position

  1. Tool guide POSITION, press the Adapt lift position button.

  2. Select the new position of the SheetMaster and confirm by clicking.

Adjust part position

  • Only for TruMatic 7000: If the new position of the SheetMaster can only be approached with extended additional axis, the additional axis is set automatically.

  2. Select the new part position and click to confirm it.

Move a carrier suction cup

A new position can be defined in the suction frame for carrier suction cups.

Circles in the SheetMaster drawing indicate the positions that can be set at the carrier suction cups. The standard position of the carrier suction cups in indicated by larger circles (see example).

The carrier suction cups can be moved by up to 150 mm as standard.

  • Manual interventions by the machine operator are required between the processing of sheets with different suction cup configuration. If carrier suction cups need to be converted, that is not automatically recognized by the machine. Conversion information is displayed in the production package and must be observed by the machine operator.

  • No message is displayed for the machine operator when the carrier suction cups need to be removed.

  1. Press tab Removal > Lift , button Convert suction cups.

  2. Confirm messages with the OK button.

The modified suction cup configuration applies to all removals with this SheetMaster and for loading.

  1. Select removal with SheetMaster where carrier suction cups are to be displaced.

  2. Select the carrier suction cup that is to be displaced.

  3. Enter the desired suction cup number in the input line and confirm with the Enter key.

  4. Select the new position of the carrier suction cup.

  5. Move any other carrier suction cups.

  6. Press the OK tool guide.

GripMaster: Remove scrap skeletons and remainder strips

Scrap skeletons can be removed automatically with GripMaster. The repositioning cylinders or presser feet can be used for repositioning.

When repositioning, the sheet is held by prongs with tool clamp. The position of the prongs with tool clamp can be adjusted in Data Manager Cut.

  • The NC file is created in the single sheet view and there is no GripMaster removal yet: A prompt appears asking if the GripMaster disposal is to be generated

  • The NC file is generated in the sheet overview: GripMaster disposal is set automatically. The clamping position for repositioning is automatically determined.

The following symbol indicates that the scrap skeleton is removed with GripMaster:

Uncontrolled release of remainder sheet due to separating cut during GripMaster removal. ** When repositioning, when creating a separating cut and when transferring the scrap skeleton to the GripMaster, each remainder sheet must be held by two clamps. For this purpose, contact Technical Service.

Strip the scrap skeleton: Parameters

Field Description

Speed:

The default value at which the Y axis of the machine moves is entered.

The value can be adjusted.

Acceleration:

The default value is entered for the acceleration at which the machine’s Y axis moves.

The value can be adjusted.

Stripping position X

The position defines where the scrap skeleton is to be set down in the stripping area.

Adopt as default

The selected settings are then displayed by default during the next call.

  • In the case of low scrap skeleton stability due to thin sheets (< 1 mm) and narrow flanges, disposal via GripMaster is not recommended. The programmer must assess the disposal in detail.

  • Presser feet may not use any self-stripping tools.

  • Do not set the repositioning position within a hole.

  • Presser feet may not use any self-stripping tools.

  • No forming height or highest position are permitted during repositioning with presser foot.

  • The MultiShear tool may not be used for repositioning with presser foot.
Requirement

  • A corresponding SheetMaster must be configured for the selected machine. Before creating the NC file, it is checked whether a scrap skeleton disposal has already been set. If there is no removal, the dialog Skeleton is shown.

  • GripMaster must be configured for the selected machine.

  • Single sheet view is active.

  1. Press tab Start > Finish , button Create NC ▼.

    • If there is no GripMaster disposal, a query appears asking if GripMaster disposal is to be created.

  2. Press the Yes button.

  3. If repositioning is required: confirm Confirm list with Yes.

    • The symbolic representation of the GripMaster is displayed. NOTE: Do not set the repositioning position within a hole.

  4. Select clamping position. To do this, click on the section of the sheet at which the sheet is to be held in place for repositioning.

  5. Select repositioning device: Click the presser foot or the repositioning cylinder.

  6. To select both repositioning devices: Press All.

  7. Confirm the message window with OK.

  8. Press Create NC again.
