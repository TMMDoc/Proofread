System pallet types

System pallet types

  • The following system pallets are configured by default for punching machines, punch laser machines and for the TruLaser Center 7030 (L26):

  • System pallet with base, empty:

    • Storage cart without base

  • System pallet without base, empty

    • Storage cart with base

  • System pallet without base, large format, empty

    • Storage cart for large format with base

  • System pallet with base, large format, empty

    • Storage cart for large format without base

Opening the configuration of the system pallet types

Requirement
A storage cart with storage connection is available.

  1. Open Data Manager Cut.

  2. Select tab Machines > Data.

  3. Press the Unloading area button.

  4. Press the Data 2 button.

Creating system pallet types

  1. Open the configuration of the system pallet types.

  2. To activate the storage connection: Set the button to Yes.

  3. Press the Create button.

  4. Enter ID. The ID is freely selectable. The ID is freely selectable. TecZone Cut automatically suggests the next free number.

  5. Enter System pallet type.

  6. Enter Remark.

  7. Press the OK button.

Changing system pallet types

Requirement
A storage cart with storage connection is available.

  1. Open the configuration of the system pallet types.

  2. Select the system pallet type to be changed.

  3. Press the Modify button.

  4. Change System pallet type or Remark.

  5. Press the OK button.

Deleting system pallet types

Requirement
A storage cart with storage connection is available.

  1. Open the configuration of the system pallet types.

  2. Select the system pallet type to be deleted.

  3. Press the Delete button.

  4. Confirm message with Yes.
