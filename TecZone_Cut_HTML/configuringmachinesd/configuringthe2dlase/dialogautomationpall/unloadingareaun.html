Unit parameters

Unit parameters

Number (ID)

Each number per unit can be allocated only once for each machine.

For punching machines and punch laser machines: Value=0 is reserved for the unloading platform. There can thus only be one unloading platform per machine.

For punching machines and punch laser machines with controls of type SINUMERIK 840D - table output in NC text (for example TC 600 L):

  • Value 2: first SortMaster pallet or dual cart

  • Value 3: second SortMaster pallet or dual cart

  • For U addresses, the Number (ID) in TruTops Boost must match the number of the SortMaster Pallet on the machine control.

Type

For assemblies that are adjacent to the palletizing area, locations of type Collision contours can be created for a better overview. The obstructions are then defined as pallets at this location. The obstructions are displayed hatched in the palletizing view.

Stacking at obstructions is not possible.

System pallet type

Only available if there is a storage connection.

For punching machines and punch laser machines, the field is only active if Storage cart or 2 storage carts above each other was selected as the type.

Remark

Any text can be entered as a comment. The comment will be output in the palletizing drawing of the pallets and in the processing information.

Position X, Y

Only available for 2D laser machines: Position of the unloading area. The reference point is the zero point of the pallet changer.

Speed, acceleration programmable?

  • Yes: The speed and acceleration of the unit can be programmed in the parameters for palletizing on the Unloading area tab.

  • No: The speed and acceleration of the unit cannot be programmed.

NC output: Y in positions

Only available for punching machines and punch laser machines:

  • Yes: For moving units that can be positioned in the Y direction, the Y value is output as the position number.
    The Y values are then permanently defined positions (typical for dual carts).

  • No: For moving units that can be positioned in the Y direction, the Y value is output in mm (typically for SortMaster Pallet).

For immobile location (for example, unloading platform): set button to "No".

Punching machines and punch laser machines: Start position

Y value of the first position. The pallet positions in Y must be matched to the start position in Y. If pallets are entered for this unit later on, the specified start position must lie within the pallet range. The pallet’s Y position must be suitably chosen.

Punching machines and punch laser machines: Start number

For movable units, the Y value should be output as the position number.

The number of the first position. Normally, 1 is entered.

Punching machines and punch laser machines: End number

For movable units, the Y value should be output as the position number.

The number of the last position. Normally, 19 is entered.

Punching machines and punch laser machines: Distance between positions

For movable storage area units, the Y value should be output as the position number.

Y distance between two adjacent positions.

  • Examples:

  • Y = 60 mm in case of SheetMaster (1300) and dual cart or storage cart

  • Y = 75 mm in case of SheetMaster (1600) and dual cart or storage cart

Weight monitoring

  • No: weight monitoring is inactive.

  • Yes: weight monitoring is active:

    • For automatic palletizing, parts are only placed on the pallets until the maximum permissible part weight of the location or pallet is reached.

    • For interactive movements, stacks can only be shifted on a pallet if the maximum permissible part weight for the pallet is not exceeded.

Max. permissible weight

Maximum part weight up to which the parts can be stacked on the pallet.

Upper/lower cart identical

Only available if Double cart or 2 Storage carts above each other was selected as the type.

  • If upper cart and lower cart are identical: set checkbox to "Yes".

    • Mandatory entry for TC 600 L with control version < 6.0

    • Pallets need to be entered only for the upper cart. The pallets for the lower cart are generated automatically.

  • If upper cart and lower cart are not identical: set checkbox to "No".

    • The pallets for the upper and lower cart must be entered separately.

    • The number and size of the pallets can be different on the upper and lower carts.

Only for TruMatic 7000: Y sorting motion

Only available if Double cart or 2 Storage carts above each other was selected as the type.

  • For 2D laser machines, the sorting movements is carried out by the LiftMaster or SortMaster as standard.

  • With punching machines and punch laser machines, the sorting movement is carried out by the unit by default.

Lower cart ID and Upper cart ID

Only available for 2D laser machines if Double cart or 2 storage carts above each other was selected as the type.

Enter an ID as desired in the Lower cart ID field.

Upper cart ID is grayed out. The entry is automatically adopted from the Number (ID) field.
