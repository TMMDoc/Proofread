Slat layout

Slat layout

Different slat layouts are available depending on the machine. The slat layouts do not depend on the type of slats.

Within the defined grid of the pallet, individual slat layouts can be defined and can be defined as the standard layout for a machine.

Slat layout parameters
Field Description

Slat assignment

  • Visible: Have slat layout as an option in the technology module.

  • Standard layout: Slat layout is standard for the configured machine.

  • Displaced slats:

Visible and Standard layout are displayed in the selection table.

Name:

Name of the slat layout. A maximum of 40 characters are permitted.

Grid:

Distance between the slats.

Number of slats

Number of slats.

Position 2. slat

Position of the 1st slat.

Slat offset

Value for the offset of the slats.
For correct tilt calculation of the parts and for the Smart Collision Prevention option, the slats must be distributed evenly.

Creating a slat layout

  1. Press the Create button in the Slat assignment area.

  2. Enter or select the parameters.

  3. Press the OK button.
    → The new slat layout is displayed in the selection list.

Modifying a slat layout

  1. Select a slat layout from the list.

  2. Enter or select the parameters.

  3. Press the Apply button.

Defining the slat layout as standard

  1. Select a slat layout from the list.

  • Only one slat can be selected as the standard slat per material.

  • Slats defined as standard slats are marked in the list of slats with a 1.

  1. Activate the checkbox Standard layout.

  2. Press the Apply button.
