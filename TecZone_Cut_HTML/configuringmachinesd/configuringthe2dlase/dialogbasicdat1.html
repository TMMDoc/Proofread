Limit values

Limit values

The limit values stored in Basic data are taken into account when the NC program is created.

Main progr. number

Largest possible main program number if only numerical program numbers are possible. The points for the main program number and subroutine number are counted together.

Subroutine number

Number of possible subroutines. Corresponds to the largest possible subroutine number if no alphanumeric program numbers are supported. The places for the main program number and the subroutine number are added up.

X value

Maximum value for the x-coordinate.

I value

Maximum value for the I-coordinate (radius for arcs).

Y value

Maximum value for the y-coordinate.

J value

Maximum value for the J coordinate (end point for arcs).

Block number

Maximum number of places for numbering lines in the NC text.

Machine drawing name

Name of the machine drawing.

Block numbering

Block numbering is necessary on machines with BOSCH control to be able to re-enter the NC program after an interruption.

If the file size of the NC program is to be reduced: Deselect option.

If the NC program is too big, it cannot be imported from the machine.

Block increment

The block increment is given in steps of ten by default. With steps of ten, additional NC blocks can be inserted on the machine without changing the entire numbering of an NC program.

General table format DIN V 4001

Standard format.

Alphanumeric program numbers

  • Yes: the name of the NC programs may be alphanumerical.

  • No: the name of the NC programs may not be alphanumerical.

Subroutine technique with programmable single-part rotation

  • Yes: Subroutines are created.

  • No: Subroutines are not created, all data is written to the main program.
