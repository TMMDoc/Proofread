Configuring machines: Data Manager Cut

The database Cut contains data used during programming. Each machine must be configured individually in the dialog before all required functions are available.

The dialog manages:

  • Machines

  • Technology tables

  • Rules

  • NC output data (NC cycles, formats, times …​)

Default values for machines and machine components are pre-allocated in the database. Available options depend on the machine selected for the current sheet program. TruTops Boost can be configured for any machine with an NC interface.

Incorrect values in the machine data can lead to inoperable NC programs.

  • Check that all entries and changes are correct.

  • If required, contact Technical Service.

Required machine data is in the current operator’s manual and the current machine programming manual.

Opening Data Manager Cut in HomeZone

  1. In HomeZone, select the Workplace category.

  2. In the results list, select a workstation.

  3. In the detail area Database, press Configure.

The machine configuration opens.

For punching machines, punch laser machines and TruLaser Center (L26), the multi-step Modify dialog opens automatically when the machine configuration is opened for a newly created machine.

Opening Data Manager Cut in TecZone Cut

  1. Open TecZone Cut.

  2. In the File tab, press Adjust machine…​.

The machine configuration opens.
