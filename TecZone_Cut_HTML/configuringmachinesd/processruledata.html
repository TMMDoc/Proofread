Parameter description: Piercing

Parameter description: Piercing

Field

Description

Contour type

Information, on the contour type for which the other parameters will be shown in the screen.

Piercing

  • If the beam is to pierce in ramp mode at reduced laser power: press soft.

  • If the beam is to pierce in ramp mode at full laser power: press Full.

  • If the beam is to pierce in ramp mode at fast laser power: press Fast.

Piercing type

  • If the beam is to pierce in ramp mode at reduced laser power: press soft.

  • If the beam is to pierce in ramp mode at full laser power: press Full.

  • If the beam is to pierce in ramp mode at fast laser power: press Fast.

Measuring cycle

Only for machines with Bosch control. The material thickness is determined via a measurement cycle.

Radius of spatter circle

Safety area in which no contour may be located. Plasma deposits can occur in the Radius of spatter circle during piercing. This safety area will be considered in the collision check.

Height regulat.

The clearance between the cutting nozzle and the workpiece is permanently measured and corrected.

Parameter description: Approach

Parameter description: Approach

Field

Description

Approach

Cutting with full or reduced cutting data at beam start.

Type

Cutting with full or reduced cutting data at beam start.

Prec.stop

NC Function. With linear interpolation, the machine moves to the target position at a speed defined in the F word. The next NC block is then read in.

Height regulation

Cutting with active distance regulation at beam start. The cutting head follows the sheet (Z axis motion) in a sensor-guided manner at a constant cutting distance.

Cutting without active distance regulation at beam start. The cutting head moves over the sheet with a constant Z position.

Path slope

Generates a constant speed over the punching transitions, in order that the laser moves over the workpiece contour at constant speed.

Feed forward

-

Reduction

-

Precut

After piercing, a cut of a few millimeters is made at reduced speed, depending on material thickness. After making the pre-cut, the laser moves at a specific speed back to the start hole before the contour is cut with the selected LTT.

Appr.angle

Angle to be used to approach inner and outer contours. By default, all TRUMPF rules are delivered with an approach angle of 0°.

  • If the approach is central to a line, central to an arc or a circle, the approach flag is at right angles to the contour.

  • If approach is made to a corner, then the approach proceeds tangentially, i.e. directly in the cutting direction at the corner.

  • A negative angle entry creates an acute angle of entrance, i. e. a major change of direction at the entrance point.
    A positive angle entry creates an obtuse angle of entrance, i.e. a minor change of direction at the entrance point.

Strategy

  • If only one contour corner is to be approached: Press at corner.

  • If only the center of a contour element (lines or arcs) is to be approached: Press at element.

  • If the preference is to approach a contour corner: Press corner/el..

  • If the preference is to approach the center of a contour element (lines or arcs): Press el./corner.

To change other approach parameters on elements or corners: Press Continue.

Path

Length of the approach path.

Radius

If Continue was used to press the shape parameter line/arc: Arc radius

Parameter description: Corner treatment

Parameter description: Corner treatment

Field

Description

Corner treatment

  • yes: Corners are rounded.

  • No: Corners are not rounded.

Type

The type of corner rounding.

If Cooling is active, no cooling is output after the approach.

Limit angle

The angle range over which the corners should be rounded. Only the corners that lie between the specified angles are rounded.

Corners

  • inner: Only inside corners are rounded.

  • outer: Only outer contours are rounded.

  • If required: inner/outer: Inner and outer contours are rounded.

Radius

If the rounding radius is to be maintained exactly, the minimum radius must correspond to the maximum radius.

Deviation

The tolerance range in which the rounding may lie is determined from these values.

Length element before corner

  • The corner is not treated in the following cases:

  • The distance before the corner is longer than the maximum value entered.

  • The distance before the corner is shorter than the minimum value entered.

Length element after corner

  • The corner is not treated if:

  • The distance after the corner is longer than the maximum value entered.

  • The distance after the corner is shorter than the minimum value entered.

Parameter description: Looping

Parameter description: Looping

Field

Description

Looping

  • yes: Corner treatment with Looping is to be activated.

  • No: Corner treatment with Looping is to be deactivated.

Form

  • Bisect. line angle: Looping is to follow the bisecting line angle of the corner.

  • Loop: Looping is to run along a loop at the corners.

Radius

Only for Form = Loop: Arc radius of the Loop

If the radius of the loop is to be complied with exactly: minimum radius = maximum radius

Length

For Form Bisect. line angle only: length of the bisecting line angle

Angle

A loop is only created at the corners whose angle is between the minimum and maximum value.

Length element before looping

  • The corner is not treated in the following cases:

  • The distance before the corner is longer than the maximum value entered.

  • The distance before the corner is shorter than the minimum value entered.

Length element after looping

  • The corner is not treated if:

  • The distance after the corner is longer than the maximum value entered.

  • The distance after the corner is shorter than the minimum value entered.

Parameter description: Vaporize

Parameter description: Vaporize

Field

Description

Vaporize

Whether the program should be created with or without vaporizing, can be decided when creating the NC program.

  • yes: The contours are to be vaporized with laser processing.

  • No: Contours are not to be vaporized with laser processing.

Type

With this setting, TRUMPF rules will be supplied for materials which are typically vaporized.

  • circular: Only a certain radius around the piercing point is to be vaporized.

  • Point: Only the piercing point is to be vaporized.

  • Contour: The entire contour is to be vaporized.

Radius

If Type was used to press the button circular: Circle radius
