Adjust dialog: Parameters

In the multi-step dialog Adapt, the general settings for the machine are defined.

Dialog Adapt: Parameters

Field Description

Active die

Activated: Machine has an "active die".

Descending die

Activated: Machine has a descending die.

Repositioning cylinder present

Activated: Machine has a repositioning cylinder. Optionally, it can be fitted with a repositioning cylinder or presser foot.

Moving table

Activated: Machine has a support table that can be moved in the Y direction. The flap opening can be enlarged by means of the moving support table.

StripLine (presser foot force programmable)

Activated: the presser foot force can be adjusted on the machine.

The force of the presser foot can be programmed in order to avoid imprints on sensitive materials.

If a value for the presser foot force is specified, the presser foot force on the machine is monitored when using the blank holder. This monitoring slows down the process of pressing down.

Sorting flap available

Punching machines and punch laser machines: Activate if the selective removal of scrap and good parts is to be supported.

Punch break sensors available

-

Small part sorting present

Activated: A SortMaster Box, SortMaster Box Linear or a conveyor belt with deflector is located below the small parts flap.

Flap (programmable in 2 positions)

TruMatic 3000 (K09) or TruPunch 3000 (S20): Activate if the conveyor belt has a switching function.

Die spray lubrication

Activated: Machine has spray lubrication. The sheet is lubricated from the bottom using spray lubrication.

Softpunch

Activated: Machine supports the "Softpunch" function. Softpunch reduces the noise level generated during punching.

Tapping

Activated: Machine supports tapping.

MultiBend

Activated: Machine supports the tool MultiBend tool for bends.

MultiShear

Activated: Machine supports the tool MultiShear in order to process parts seamlessly.

MultiTool

Activated: Machine supports MultiTool. When a MultiTool tool is selected, the clamp contour for MultiTool and standard tools is automatically activated.

Slotting

Activated: Machine supports the slotting tool. The 30 x 5 slotting tool can be used (feed = 5 mm).

Carving

Activated: Machine supports the tool Carving.

Quick forming

Activated: Machine supports the tool Quick forming. Quick beading is possible in the forming area.

Marking

Activated: Machine supports the tool Marking. The marking tool can be used for marking.

Marking underside of the sheet

Activated: Machine supports the tool Marking the underside of the sheet.

Roller tools

Activated: Machine supports the Roller tools.

Adaptive stroke calibration

Activated: Machine is equipped with Adaptive stroke calibration. After a measurement the ram stroke will be exactly adjusted for the current material thickness.

Loading table

Activated: Machine is equipped with an auxiliary table for the SheetMaster.

Integrated flattening

Activated: Machine supports the function Integrated flattening.

Automatic scrap skeleton disposal available

Activated: Machine can remove scrap skeletons automatically.

  • Low-scratch processing

  • Ball-bearing tables with brush sets

Activated: Machine supports Low-scratch processing or ball-bearing tables with brush sets.
Which of the two options is available, depends upon the age of the machine.

Presser foot force adjustable

Activated: Presser foot force is to be manually adjustable. The force of the presser foot can be programmed in order to avoid imprints on sensitive materials.

Performance package

Activated: Performance option before laser cutting is available.

Clamps can be individually opened

Activated: Clamps can be opened individually.

Clamp groups available

-

Variable suction system

Activated: Machine supports the function Variable suction system.

Tool lubrication

Activated: Machine supports the function Tool lubrication.

Deburring

Activated: Machine supports the tool Deburring.

Small parts ejection

Activated: Machine supports the Small part ejector function.

Small parts can then be ejected using an ejector tool.

Dot Matrix Code (restricted)

Activated: On the machine, part identification can be produced with a tool.

If this option is activated, the option Dot Matrix Code (part identification) must not be activated!

Dot Matrix Code (part identification)

Activated: On the machine, part identification can be produced with a tool or the laser.
If this option is activated, the option Dot Matrix Code (restricted) may not be activated!

Punching machines, punch laser machines: "Adapt" dialog

  • The available options are machine-dependent. The machine options are listed in the order confirmation.

  • TruTops Boost compensates for machine options with the entered machine control version. Machine options that are not available for this machine control version are marked with an exclamation mark. A note is displayed.

  1. Open Data Manager Cut.

  2. Select tab Machines > Adapt.
    → The first list of the multi-step dialog opens.

    The machine is configured via a sequence of several dialogs.

  3. Check the default setting and change if necessary.

  4. Press the Continue button.

  5. Select other machine options.

  6. To close the dialog, press the Exit button.
