NC output parameters

NC output parameters

Remark

Entries from this field are displayed in HomeZone in the machine management in the category New workplace, selection field Machine, column Note 1.

  • The letters "R", "S" and "V", indicate the clamp type:

  • R = retractable clamps

  • S = penetrating clamps (linear magazine)

  • V = transitional clamps can be freely moved on the linear magazine

Note 2

Name of the machine workstation. The name is selected when creating the machine in HomeZone in the machine management. The name cannot be changed later.

Show interface name instead of official name

  • Yes = In the machine selection menu, the old machine name before the TRUMPF name change or the development name will be shown. For machines which only have a new name, the TRUMPF development name will be displayed.

  • No = The interface name will not be displayed.

Block numbering

If the file size of the NC program is to be reduced: Deselect option.

If the NC program is too big, it cannot be imported from the machine.

Block numbering is necessary on machines with BOSCH control to be able to re-enter the NC program after an interruption.

Block increment

The block increment is given in steps of ten by default. Due to the steps of ten, additional NC blocks can be inserted on the machine without changing the entire numbering of an NC program.

Transfer technology tables

Laser technology tables and tool master data from TRUMPF are already stored in the database on the machine control. It is not necessary to output them. Self-created laser technology tables and tool master data that are not yet available at the machine control must be sent to the machine with the NC program. If the data is already available on the machine, the transferred values are ignored.

Strategy - Part-oriented

Certain processing sequences which are repeatedly executed on a sheet are written in a separate subroutine. This subroutine can be called up repeatedly within the main program.

The system searches for identical processing sequences within the active sheet. These processing sequences are written in subroutines according to the defined rules.

Strategy - Compulsory sequence

The processing operations in compulsory sequences are written into subroutines.

Minimum number of calls

Can only be specified if Part-oriented is selected.

Minimum number of processing

Can only be specified if Part-oriented is selected.
