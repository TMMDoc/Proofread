Parameter data 1: General lift data for loading and unloading

Parameter data 1: General lift data for loading and unloading

Lift name

  • SheetMaster from 1/95: The lift name corresponds to the program version number on the nameplate.

  • GripMaster

  • All S-lifts: The lift name is displayed.

Drawing name

To display the SheetMaster, there is a drawing of the lift in TRUMPF delivery condition under >\\localhost\TruTops_Shared\Cut\Lift.

Position from the operator’s view (loading and unloading)

The operator is standing in front of the machine looking in the direction of the machine.

NC output format (loading and unloading)

  • direct: All lift functions are output at the point where they are needed.

  • time-optimized: All preparatory functions such as suction cup coupling or lift coordinates are output as early as possible in order to integrate the transmission time into the machine runtime.

Peeling package (loading)

yes: peeling package option available on SheetMaster.

  • Peeling package (loading) is grayed out:

    • Lift has no loading function.

    • The peeling package option is not available for the lift. This option is defined by TRUMPF in the database.

Sheet thickness detector (loading)

Sheet thickness detector (loading) is grayed out if the lift has no loading function. This option is defined by TRUMPF in the database.

  • manual:

    • A double sheet detector is available, but cannot be programmed.

    • A double sheet detector is not available.

  • mechanical: The material thickness is checked by a probe arm.

  • inductive: The material thickness is checked inductively. The double sheet detector is programmable.

Prepare loading at program end (loading)

Prepare loading at program end (loading) is grayed out if the lift has no loading function. This option is defined by TRUMPF in the database.

The SheetMaster already starts loading a new sheet while a sheet is being processed.

These options are used to define the default settings. Apart from impossible, the performance can be modified under NC program.

  • impossible: In this case, preparatory loading is not possible at all, and this setting is applied as the default.

  • No: Preparatory loading is possible but is not preset.

  • yes: Preparatory loading is possible and is preset.

Maximum carrying capacity

Maximum admissible weight that the SheetMaster is permitted to transport for loading and unloading. The weight is specified in kg.

The parameters for Loading and Unload are grayed out depending on whether the lift has a loading function, unloading function or both functions. This option is defined by TRUMPF in the database.

X dimension sheet edge lift zero point

Loading and Unload: X dim. measured in mm from the sheet edge to the zero point of the SheetMaster.

The parameters for Loading and Unload are grayed out depending on whether the lift has a loading function, unloading function or both functions. This option is defined by TRUMPF in the database.

X dimension sheet edge lift reference point

Loading and Unload: X dim. measured in mm from the sheet edge to the reference point of the SheetMaster.

The parameters for Loading and Unload are grayed out depending on whether the lift has a loading function, unloading function or both functions. This option is defined by TRUMPF in the database.
