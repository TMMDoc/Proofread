Parameter data 5: Dimensions and dynamics for unloading

Parameter data 5: Dimensions and dynamics for unloading

Requirement
Only active for lifts with single part removal.

NC output format

Definition of whether speed and acceleration have to be output in the NC program in steps or in %.

The field is active for all lifts currently available in TruTops Boost and defined by TRUMPF.

NC output format is grayed out for very old lifts if the speed and acceleration cannot be output for this lift in the NC program.

NC output acceleration

Definition of the acceleration levels from 1-6. Each acceleration level is assigned to a certain acceleration in m/s².

NC output speed

Definition of the speed level from 1-6. Each speed level is assigned to a certain speed in m/min.

NC output acceleration from scrap skeleton Z

Definition of what % of the maximum acceleration should the lift accelerate to when lifting suctioned parts out of the scrap skeleton.

1. Dropping height Z

Specification of the minimum height for the regular dropping of parts onto units, which are located under the machine table.

The 1st dropping height in Z corresponds to the value of the maximum dropping height. See data 6.

The functions Soft dropping and Depositing are not possible in the area below the machine table.

Retract from clamp dY

Specification of the travel distance in Y direction to move a part from the clamping area.

Traversing speed

Speed with which the travel motion is to be executed for release from the clamp.

Check punching head - lift pedestal distance X, Y

Dimension from the punching head center to the front edge of the first lift pedestal in X direction or Y direction.

Maximum X traverse path during Y return stroke

X traverse path during the Y suction frame displacement return.

X unloading area outside machine

Start and End: Define the area in which production parts or the scrap skeleton can be deposited. The unloading table with pallets is normally located in this area.

Traverse path limit X

Additional help for restricting the travel range of a lift.

  • If traverse path limit X is active:

    • Left: Maximum position lift zero point X must be greater than Start.

    • Right: Maximum position lift zero point X must be less than Start.

Maximum position lift zero point X

Maximum position lift zero point X is grayed out if "No" is set for Traverse path limit X.

Maximum position lift zero point X must be less than End.

Palletizing under table

This defines whether an unloading area should also be defined under the machine table.

Start inside machine

Start inside machine is grayed out if "No" is set for Palletizing under table.

The start of the unloading area under the machine table related to the machine zero point (punching head).

  • When palletizing under table active:

    • For right-hand installation: Start inside machine must be greater than Start.

    • For left-hand installation: Start inside machine must be less than Start.
