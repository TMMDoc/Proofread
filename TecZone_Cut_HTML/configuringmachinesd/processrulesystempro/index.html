System process rules

System process rules

  • In the set of machine rules, variables allow specific settings to be made for the active machine. The variables in the process rules concern all machines and the complete programming system.

  • In the internal, password-protected rules, variables can only be changed with the help of Technical Service.

  • Changes to the public rules are retained after an update.

Deleted or incorrect variables can lead to inoperable NC programs!

  • Do not delete TRUMPF variables.

  • Check all entries and changes.

  • If required: contact Technical Service.
By entering filter criteria, the number of variables displayed can be limited.

LaserSimulationSpeedDelays

Individual simulation steps are calculated and displayed during the simulation. The next step is delayed after each representation.

  • Enter 10 values that correspond to the 10 positions of the slider for the simulation speed surface. The higher the values that are entered here, the slower the simulation. Presetting: 300,200,150,100,75,60,55,50,15,1.

  • Separate each of the 10 values by a comma.

  • Typical values are in a range of 250 ms to 1 ms.

  • Save the values by pressing the Apply button.

  • Restart TruTops Boost.

LaserSimulationSpeedSkips

If the selected waiting time for the simulation is already very short, the simulation can be accelerated further by skipping steps.

  • Enter 10 values that specify the number of skipped steps for the individual positions of the slider. Presetting: 0,0,0,0,0,0,5,10,25,50.

  • Separate each of the 10 values by a comma.

  • Save the values by pressing the Apply button.

  • Restart TruTops Boost.
