Process rule > Machine: Machine rules for 2D laser machine

Process rule > Machine: Machine rules for 2D laser machine

  • In the set of machine rules, variables allow specific settings to be made for the active machine. The variables in the process rules concern all machines and the complete programming system.

  • In the internal, password-protected rules, variables can only be changed with the help of Technical Service.

  • Changes to the public rules are retained after an update.

  • The variable shown in the machine rules depends on the active machine.

Deleted or incorrect variables can lead to inoperable NC programs!

▶ Do not delete TRUMPF variables.
▶ Check all entries and changes.
▶ If required: contact Technical Service.

By entering filter criteria, the number of variables displayed can be limited.

FoilThicknessConsideredInPalletizing

  • Single-film sheet: the value of
    FoilThicknessConsideredInPalletizing
    is added to the sheet thickness.

  • Double-film sheet: double the value of
    FoilThicknessConsideredInPalletizing
    is added to the sheet thickness.

  • The value for FoilThicknessConsideredInPalletizing is 0.0 mm in delivery condition. The value applies to all materials and films.

  • The value is taken into account for newly created removals.

    Exception: for SheetMaster withdrawals (not AK09), the value is also taken into account for existing removals.

NcWriteScrapGeometry

  • When a scrap part is unloaded with an unloading automation system:

  • 0 = Geometric data of the scrap part is not written to the NC program file. Remainder sheets disposed of with the SheetMaster (scrap or scrap skeleton with suction cup) are assigned a removal number on the machine.

  • 1 = Geometric data of the scrap part is written to the NC program file. Remainder sheets disposed of with the SheetMaster (scrap or scrap skeleton with suction cup) are displayed on the machine as a graphic.

  • When the NC program is created, the contour of the scrap part is written to the NC program file and displayed on the machine during disposal.
