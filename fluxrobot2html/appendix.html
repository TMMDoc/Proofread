Glossary of Terms

FluxRobot - A robotic bending automation system that integrates a robot arm, bending machine, and associated hardware and software components to perform automated bending operations.

FluxRobot Cell - The complete robotic bending cell, including the robot arm, bending machine, cell components (Pickup Pallet, Centering Table, Deposit).

FluxRobot CAM - The offline programming environment used to define bend sequences and robot motion, generating a .rbc file containing all motion data and ram points.

Right-Angle Control - The human-machine interface software that manages the bending machine operations and coordinates timing with the robot controller.

Post-Processor - A Windows executable that converts the .rbc file produced by FluxRobot CAM into a set of .LS robot program files ready for upload to the robot controller.

User Frame (UFRAME) - A coordinate system defined on the robot controller that represents the position and orientation of a station (e.g. Machine, Pickup Pallet, Centering Table, Deposit).

Tool Frame (UTOOL) - A coordinate system defined at the tip of the robot’s end-effector (gripper), used as the reference for all tool motions.

Backgauge (BG) - Motorised stops inside the bending machine that the operator or robot pushes the sheet against to achieve the correct bend position.

Regrip - An intermediate step where the robot releases and re-grasps the part in a different orientation to allow subsequent bends that would otherwise be unreachable.

Home Position - The safe, neutral position the robot returns to at the start and end of every cycle.
