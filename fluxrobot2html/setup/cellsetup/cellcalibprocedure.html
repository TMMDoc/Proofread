Cell Calibration Procedure

This section provides a step-by-step guide to calibrate the robot cell for accurate bending operations.

Pre-Calibration Checklist

  • First ensure that the robot is in the home position and the cell is clear of any obstructions.

  • Make sure that the robot is in teach mode (T1/T2).

Procedure

The following procedure is followed to calibrate the robot cell:

  1. Pointed Tool Calibration: Firstly, the calibration tool (Pointed Tool) has to be calibrated. Finding its Tool Center Point (TCP) is essential because this calibration tool is used for calibrating the User frames in the cell.

    To find the TCP of the calibration tool, follow these steps:

    1. Pre-setup for TCP Calibration has to be done before recording any TCP points.

    2. Setup has to be done to set the Tool frame as zero tool.

    3. Navigate to Tool’s Frame number 1 in Teach Pendant. The TCP values of the calibration tool will be stored in Frame 1.

    4. Use the Three-Point Method For Tool Frame to calculate the TCP of the calibration tool.

  2. Machine Frame (User Frame-1) Calibration: After finding the TCP of the calibration tool, the next step is to calibrate the machine frame (User Frame-1) using the calibration tool.

    1. Make sure that the calibration tool is mounted on the robot.

    2. Press Shift + Coord to set the tool frame as 1 since the TCP of the calibration tool is stored in Tool Frame 1.

    3. Place the Machine’s calibration plate exactly at the center of the machine.

    4. Navigate to User Frame-1 in Teach Pendant. The machine frame will be stored in User Frame-1.

    5. Use the Three-Point Method For User Frame to calibrate the machine frame (User Frame-1).

  3. Pickup Pallet (User Frame-2) Calibration: After calibrating the machine frame, the next step is to calibrate the pickup pallet frame (User Frame-2) using the calibration tool.

    1. Place the Pickup Pallet’s calibration plate exactly on top of the pickup pallet.

    2. Navigate to User Frame-2 in Teach Pendant. The pickup pallet frame will be stored in User Frame-2.

    3. Use the Three-Point Method For User Frame to calibrate the pickup pallet frame (User Frame-2).

  4. Centering Table (User Frame-3) Calibration: After calibrating the pickup pallet frame, the next step is to calibrate the centering table frame (User Frame-3) using the calibration tool.

    1. Place the Centering Table’s calibration plate exactly on top of the centering table.

    2. Navigate to User Frame-3 in Teach Pendant. The centering table frame will be stored in User Frame-3.

    3. Use the Three-Point Method For User Frame to calibrate the centering table frame (User Frame-3).

  5. Deposit (User Frame-4) Calibration: After calibrating the centering table frame, the next step is to calibrate the deposit frame (User Frame-4) using the calibration tool.

    1. Place the Deposit’s calibration plate exactly on top of the deposit.

    2. Navigate to User Frame-4 in Teach Pendant. The deposit frame will be stored in User Frame-4.

    3. Use the Three-Point Method For User Frame to calibrate the deposit frame (User Frame-4).
