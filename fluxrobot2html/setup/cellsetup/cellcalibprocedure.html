Cell Calibration Procedure

This section provides a step-by-step guide to calibrate the robot cell for accurate bending operations.

Pre-Calibration Checklist

  • First ensure that the robot is in the home position and the cell is clear of any obstructions.

  • Make sure that the robot is in teach mode (T1/T2).

Procedure

The following procedure is followed to calibrate the robot cell:

1. Pointed Tool Calibration

Firstly, the calibration tool (Pointed Tool) has to be calibrated. Finding its Tool Center Point (TCP) is essential because this calibration tool is used for calibrating the User frames in the cell.

Pre-setup: Pre-setup for TCP Calibration has to be done before recording any TCP points.

Setup: Setup has to be done to set the Tool frame as zero tool.

TCP Calibration using Three-Point Method:

  1. In the Teach Pendant, go to Menu → Setup → Frames → Other → Tool Frame.

  2. Navigate to Tool Frame 1 in the Teach Pendant. The TCP of the calibration tool will be stored here.

  3. Slowly jog the robot until the calibration tool tip touches the reference tool tip precisely. Press SHIFT + RECORD to save Approach Point 1.

  4. Move away, then change the robot’s wrist/arm angle clearly before approaching again — do not approach from the same direction.

  5. Repeat the steps c and d for Approach Point 2 and Approach Point 3. While saving the points, ensure that it is being recorded at the respective approach point space in the selected tool frame.

  6. The robot will automatically calculate the TCP once all three points are recorded.

    The 3 approach points must be coplanar and non-collinear. If they are collinear, the TCP values (X, Y, Z, W, P, R) will all be zero.

2. Machine Frame (User Frame-1) Calibration

After finding the TCP of the calibration tool, calibrate the machine frame.

  1. Ensure the calibration tool is mounted on the robot.

  2. Press SHIFT + COORD on the Teach Pendant, select Tool, then press 1 to set the active tool frame to Tool Frame 1 (where the calibration tool’s TCP is stored).

  3. Place the Machine’s calibration plate exactly at the center of the bending machine.

  4. In the Teach Pendant, go to Menu → Setup → Frames → Other → User Frame. Navigate to User Frame 1.

  5. Place the calibration tool tip precisely at the origin point of the machine frame. Press SHIFT + RECORD to save the Orient Origin Point.

  6. Move the tool tip approximately 100 mm along the desired X direction. Press SHIFT + RECORD to save the X-Direction Point.

  7. Return to the origin point (press SHIFT + MOVETO on the recorded origin point), then move ~100 mm along the desired Y direction. Press SHIFT + RECORD to save the Y-Direction Point.

  8. The robot will automatically calculate User Frame 1.

    While recording all three points, ensure the calibration tool tip is perpendicular to the calibration plate surface.

3. Pickup Pallet (User Frame-2) Calibration

After calibrating the machine frame, calibrate the pickup pallet frame.

  1. Ensure the calibration tool is mounted on the robot.

  2. Press SHIFT + COORD on the Teach Pendant, select Tool, then press 1 to set the active tool frame to Tool Frame 1 (where the calibration tool’s TCP is stored).

  3. Place the Pickup Pallet’s calibration plate plate exactly on top of the pickup pallet.

  4. In the Teach Pendant, go to Menu → Setup → Frames → Other → User Frame.Navigate to User Frame 2 in the Teach Pendant.

  5. Place the calibration tool tip at the origin point of the pallet frame. Press SHIFT + RECORD to save the Orient Origin Point.

  6. Move ~100 mm along the desired X direction. Press SHIFT + RECORD to save the X-Direction Point.

  7. Return to the origin, then move ~100 mm along the desired Y direction. Press SHIFT + RECORD to save the Y-Direction Point.

  8. The robot will automatically calculate User Frame 2.

4. Centering Table (User Frame-3) Calibration

After calibrating the pickup pallet frame, calibrate the centering table frame.

  1. Ensure the calibration tool is mounted on the robot.

  2. Press SHIFT + COORD on the Teach Pendant, select Tool, then press 1 to set the active tool frame to Tool Frame 1 (where the calibration tool’s TCP is stored).

  3. Place the Centering Table’s calibration plate exactly on top of the centering table.

  4. In the Teach Pendant, go to Menu → Setup → Frames → Other → User Frame.Navigate to User Frame 3 in the Teach Pendant.

  5. Place the calibration tool tip at the origin point of the centering table frame. Press SHIFT + RECORD to save the Orient Origin Point.

  6. Move ~100 mm along the desired X direction. Press SHIFT + RECORD to save the X-Direction Point.

  7. Return to the origin, then move ~100 mm along the desired Y direction. Press SHIFT + RECORD to save the Y-Direction Point.

  8. The robot will automatically calculate User Frame 3.

5. Deposit (User Frame-4) Calibration

After calibrating the centering table frame, calibrate the deposit frame.

  1. Ensure the calibration tool is mounted on the robot.

  2. Press SHIFT + COORD on the Teach Pendant, select Tool, then press 1 to set the active tool frame to Tool Frame 1 (where the calibration tool’s TCP is stored).

  3. Place the Deposit’s calibration plate exactly on top of the deposit.

  4. In the Teach Pendant, go to Menu → Setup → Frames → Other → User Frame.Navigate to User Frame 4 in the Teach Pendant.

  5. Place the calibration tool tip at the origin point of the deposit frame. Press SHIFT + RECORD to save the Orient Origin Point.

  6. Move ~100 mm along the desired X direction. Press SHIFT + RECORD to save the X-Direction Point.

  7. Return to the origin, then move ~100 mm along the desired Y direction. Press SHIFT + RECORD to save the Y-Direction Point.

  8. The robot will automatically calculate User Frame 4.
