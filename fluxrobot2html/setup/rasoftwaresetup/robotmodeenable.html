Robot Mode Enable

Robot Mode Enable

Pre-requisites

  • License: In Right Angle, ensure that the Robot Interface license is activated. Only if this license is activated, robot programming and operation can be performed in Right Angle.

    • To verify the license in Right Angle, navigate to Settings → Other Settings → Machine Settings → Change access level to Service and enter the service password → Go to Maintenance → License → Verify whether the Robot Interface license is activated.

  • Enable Robot Interface: In Right Angle, ensure that the Robot Interface is enabled.

    • Navigate to Settings → Other Settings → Machine Settings → Change access level to Service and enter the service password → Go to PLC options → Verify that the Robot Interface is turned ON.

  • Robot Digital Input Configuration: In Right Angle, ensure that the Robot Digital Input Configuration is set to Open (NO).

    • Navigate to Settings → Other Settings → Machine Settings → Change access level to Service and enter the service password → Go to Digital Input Config → Robot Configuration → Verify that all the Robot Digital Input is set to Open (NO).

Robot Mode enable

  • Turn the Robot Key ON in the press brake to enable robot mode. The following message will appear on the HMI: "Robot Mode Key is Active".

  • Within few seconds after the above message, the "Special mode disparity" message will appear on the Right Angle. This message is just a warning to make the user aware that the machine is in Robot Mode. Click on the message to clear it.

The safety parameters set in machine’s manual mode will not work when Robot Mode is enabled.
