Import Gripper from STL file

Gripper folder

Gripper folder structure

Create a folder with the respective gripper name. The gripper folder should contain the following files:

  • STL file: The 3D model of the gripper in STL format.

  • DAT file: The gripper configuration file in DAT format.

Ensure that the DAT and STL files are placed in the same folder. Both DAT and STL files must have the same name as the gripper folder name.

DAT file

DAT file has to be created by the user.

The DAT file should have the following details:

  • The name of the gripper.

  • The model name of the suction cup used with the gripper.

  • The suction cup’s Z position value

  • The number of suction cups used with the gripper.

  • The X and Y positions of each suction cup relative to the gripper’s origin.

  • The gripper’s origin is the point where the robot’s J6 end connects to the gripper. During creation, the origin point of the gripper must be at the center of robot’s J6.

  • The X, Y and Z positions of the suction cups are defined with respect to the gripper’s origin point. So make sure while creating a 3D gripper CAD model, the origin point of the gripper is set correctly.
Sample File

Al_Vac.DAT

STL file

The gripper is created in a CAD software and saved as an STL file.

Importing STL file into FluxRobot CAM

The STL file can be imported into the FluxRobot CAM by navigating to Database → Bend Grippers → Import → select and import the STL file.
