Architecture

Architecture

The below image displays the overall system architecture of the FluxRobot Cell. It provides a visual representation of how different components interact with each other within the robotic system.

Hardware

The hardware setup consists of the field elements that perform and control the physical work:

Component Role

Robot Arm

Executes all pickup, centering and deposit motions inside the cell.

Robot Controller

Manages robot motion. Hosts the user frames that define coordinate systems for each station. Receives synchronisation signals from the Right-Angle controller at runtime.

Bending Machine

The press brake where bending takes place. Contains the ram (moving upper tool) and lower tool.

Right-Angle (RA) Controller

Press brake controller. It drives the machine and coordinates timing with the robot controller.

Junction Box (Optional)

Central wiring interface. Routes signals between the robot controller, Right-Angle controller, and peripheral devices such as back gauges, grippers, and safety interlocks.

Cell Components

Pickup pallet, Centering table, and Deposit station - all enclosed within the robot safety fence.

Software

Component Role

FluxRobot CAM

It is an offline programming software. Users define the bend sequence and robot motion. Flux generates a .rbc file containing all motion data and ram points.

Right-Angle Control

It is a Human Machine Interface software. Manages the bending machine operations and coordinates timing with the robot controller.

Post-Processor

A Windows executable that converts the .rbc file into a set of .LS robot program files ready to upload to the robot controller.
