Centering table

Centering table

Once the part picked from the Pickup Pallet is positioned on the Centering table, the Combi gripper uses its jaw-type feature to take the part from the Centering table for bending and then deposition.

Prior to performing the bending operation, it is essential to ensure that the part is accurately centered and oriented on the centering table. This step is crucial for achieving precise bending results.

Pallet panel

The Pallet panel will be open when you directly click on the centering table component. This panel is used to select a Centering table and position it in the cell.

  • Use the Name choice to select a required component. Turn off the Filtered check to see all available list.

  • Moving the mouse over a name in the names list displays a quick summary of that components, along with a thumbnail:

  • Use the Position inputs to position the centering table in X and Y (in cell coordinates) and use Lift input to position the centering table in Z.

  • Use the Angle input to rotate the centering table in R (in cell coordinates).

  • Use Tilt X angle and Tilt Y angle to tilt the centering table about the X and Y axes respectively. As you move or rotate the centering table, the part stack on the centering table, and the gripper/robot all follow the movement.

  • Use the Next and Prev buttons to navigate to the other pallets in the cell.

  • Use the Pickup navigation button to edit the position of the part-stack on the pallet.

  • Use for Pickup option disables the pickup pallet component and uses the centering table to perform the pickup operation.

  • Use for Centering option enables the pickup pallet component and uses the centering table to perform the centering operation.

  • Use the Save Config button under the Advanced section to save this cell configuration (including all pallets) as a default for this machine.

Part panel

The Part panel is used to edit the part position on the centering table.

  • Use the Position inputs to position the part on the centering table; these coordinates specify the center of the part in X and Y, relative to the corner of the centering table, and are in the centering table’s local coordinate space.

  • Use the Angle input to rotate the part around in the centering table.

  • Rest Part Position can be changed in X and Y. The corner is taken as reference, and it corresponds to 90 degree part rotation.

Gripper panel

The Gripper panel is used to select a different gripper, or to change the position and orientation at which the gripper picks up the part.

  • Use the Name choice to select a different gripper.

  • Use the Next Heading button to rotate the gripper around to another side of the part (it rotates in 90° steps).

  • Use the Position inputs to move the gripper-center relative to the part-center, and use the Angle input to rotate the gripper, relative to the part’s orientation.

  • Use the Swivel Neck option to rotate the Jaw Neck with 180° rotation.

  • Enabling Alt Pickup option helps to use an alternative pickup point on the part. Note that there are only 2 pickup slots in the centering table so, Alt Pickup alternates pickup between these two pickup slots.

  • Use the Set Grip Plane to select a different plane to grip. When this option is selected, the mouse pointer will change to a blue color plus symbol. Hover around to see the plus symbol showing different plane orientation and select a desired plane.

  • Use Vacuum Grip option to enable vacuum suction feature for picking the part from the centering table.
