Motion Sequences

This section describes the complete motion sequence that the robot follows during an automated bending cycle. A single cycle consists of four main phases, executed in order:

  1. Pickup — The gripper picks a sheet from the pickup pallet.

  2. Centering — The sheet is placed on and re-picked from the centering table for accurate positioning.

  3. Bend Positioning — The gripper inserts the part into the bending machine, the bend is performed, and the gripper regrips if needed.

  4. Deposit — The finished part is placed on the deposit pallet and the gripper returns to the home position.

Motion coordinate types

Each waypoint in the motion sequence uses one of the following coordinate types:

Type Description

JC (Joint motion in Cartesian coordinates)

The robot moves in joint interpolation with waypoints stored as Cartesian coordinates.

LC (Linear motion in Cartesian coordinates)

The robot moves in a linear interpolation with waypoints stored as Cartesian coordinates.

JJ (Joint motion in Joint coordinates)

The robot moves in joint interpolation with waypoints stored as joint coordinates.

LJ (Linear motion in Joint coordinates)

The robot moves in a linear interpolation with waypoints stored as joint coordinates.

Phase overview

Phase Description Waypoints

Pickup Pallet

Gripper moves from home to the pickup pallet, contacts and suctions the top sheet, separates it from the stack, lifts clear, and transitions toward the centering table.

6

Centering Table

Gripper drops the sheet on the centering table for alignment, lifts away, then re-approaches and picks the centered sheet before transitioning to the bending machine.

8

Bend Positioning

Gripper inserts the part into the bending machine, aligns it against the backgauge, and the synchronized bending process occurs. Includes optional regrip phases when the part needs to be re-grasped between bends.

17

Deposit

After the final bend, the gripper transitions to the deposit pallet, releases the finished part, and returns to the home position ready for the next cycle.
