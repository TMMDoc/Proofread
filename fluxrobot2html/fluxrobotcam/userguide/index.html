User Guide

FluxRobot CAM is offline software for robot-assisted bending. This guide describes how to use FluxRobot CAM to program the robot for automated bending operations.

FluxRobot CAM includes the following specific operations when computing a solution:

  • Gripper selection - Picks the right gripper for the part based on its shape and size.

  • Gripper position - Finds a stable position on the part where the gripper can hold it securely.

  • Pickup - Plans how the robot picks up the blank from the pallet.

  • Bending trajectory - Works out how the robot inserts the part into the machine, holds it during each bend, and pulls it out afterwards.

  • Regrip - If the robot needs to release and re-grasp the part mid-way through bending (to reach certain bends), this step inserts those moves automatically.

  • Deposit - Plans how and where the finished part is placed on the output pallet.

FluxRobot CAM simulation

Open a part, and press the B to compute the solution.

Bending solution for the most recently used bending machine will be computed automatically. If a different bending machine is required, click on the machine name in the document tab and select a different machine.

As you edit the solution, collision check happens instantly every time you edit the solution, and the results are updated in the navigator grid on the top.
