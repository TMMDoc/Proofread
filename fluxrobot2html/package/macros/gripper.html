Gripper

M_FUNCCOMBIGRIPPER.LS

This macro is a gripper control macro, that accepts three arguments to determine gripper’s behavior. The following comment lines are given in the Gripper macro to explain the argument structure:

Arguments

Gripper control using AR[1,2,3]
1 = TYPE (10=Vac, 20=Combi)
2 = VAC (1=ON, 2=OFF)
2 = PINCH (11=Close, 12=Open)
3 = CMBVAC (0=NA, 1=Fwd, 2=Bwd)

AR[1] selects the gripper type (for example, Vacuum or Combi), AR[2] specifies the action (for example, Vacuum ON/OFF or Jaw open/close), and AR[3] controls the Combi gripper movement (for example, forward or backward).

Call

The following line in the Sub_<Filename>.LS program calls the gripper macro to operate the required gripper:

Call FUNCCombiGripper(10,1,0) ;

The arguments in the above line indicate that the macro should select the vacuum gripper (10), turn the vacuum ON (1), and since it’s not a Combi gripper, the third argument is set to 0 (NA).
