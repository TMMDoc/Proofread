Sheet Alignment

Sheet Alignment

M_SA_ALIGN.LS

Sheet Alignment macro is responsible for accurate alignment of the sheet against the backgauge before bending. This macro is called after the robot’s Mute waypoint.

The macro supports two modes — Single Backgauge and Dual Backgauge — selected by the third argument (AR[3]).

Flowchat’s Summary

After the robot reaches the Mute waypoint , the bend positioning program calls the Sheet Alignment macro. The macro first checks the number of backgauges used (AR[3]) to determine which backgauge alignment mode to execute.

Single Backgauge alignment: In single backgauge mode, the robot pushes the sheet toward the backgauge with a Y-offset of 1 mm per step. It continuously reads the analog Z values from the backgauge probe(s) and stops (skips) when either Z value reaches the expected Z value (AR[2]). After alignment, the macro resets all I/O and pauses.

Dual Backgauge alignment: Dual backgauge mode uses a decision loop that compares the two backgauge probe readings (Z1 and Z2) to determine which side of the sheet contacts the backgauge first. The loop runs until both probes reach the expected Z value:

  1. Initial approach — The robot pushes the sheet forward with a 0.5 mm Y-offset per step. The macro checks whether Z1 or Z2 makes contact first (i.e. the probe value is at least 0.25 mm lower than the other).

  2. Contact detected on one side (Z1 or Z2) — The macro calculates the difference between the two probe values and stores it as the twist offset. It then:

    1. Signals the PLC to update the backgauge frame (DO[69]).

    2. Calls Frame Set to recalculate and apply the new backgauge user frame based on the contacted side’s position.

    3. Signals the PLC to calculate the TCP shift (DO[70]).

    4. Calls Twist Adjust, which internally:

      1. Calls Tool Info to send the current TCP data and position to the PLC.

      2. Calls Get Shift TCP to read the corrected TCP values back from the PLC.

      3. Writes the new tool frame and applies the tool offset to twist the sheet.

    5. After twisting, the robot advances 0.5 mm in Y and re-enters the decision loop to check both sides again.

  3. Both sides reach the expected Z value — When both Z1 and Z2 are within tolerance of the expected value, the macro performs a final linear push until both probes are at or below AR[2].

  4. Reset — All backgauge-related I/O signals (DO[66], DO[68], DO[69], DO[70]) are turned OFF and the macro pauses, leaving the sheet aligned and ready for the Pinch Point phase.

Arguments

AR[1,2,3] values are :
1 = Set Z Value [The user determines this Z value where the sheet makes initial contact with the backgauge.]
2 = Expected Z Value [The user determines this Z value where the sheet makes complete contact with the backgauge.]
3 = No. of BG usage [No. of backgauges used for alignment.]

When AR[3] is
1 → Backgauge 1 is used
2 → Backgauge 2 is used
3 → Both backgauges are used
0 → No backgauges are used

Call

Call SA_ALIGN(6.5,3.855,3) ;

The arguments indicate: initial Z value = 6.5, expected Z value = 3.855, and both backgauges are used (3).

Frame Set (Backgauge)

M_SAFRAMESET.LS

Frame Set macro calculates and updates the backgauge user frame based on the current backgauge position. It gets the current BG position from PLC and calculates the current BG position’s frame from the calibrated zero BG frame. Once the new frame is calculated, it updates to the new backgauge user frame.

Arguments

This macro accepts three arguments:

AR[1,2,3] values are:
1 = UFrameNum - New BG Frame, [This is a User Frame number. It determines in which frame number the new backgauge frame will be stored.]
2 = R - BG’s Z1/Z2-Position, [This is a Register ®to store the Backgauge’s Z1/Z2 position. It is the current position of the backgauge.]
3 = Calibrated zero BG-UFrameNum [This is a Position Register (PR). The calibrated zero backgauge user frame values are stored in this PR.]

Call

CALL SAFRAMESET(12,21,77)

The arguments indicate: the new backgauge frame will be stored in UFrame 12, the current Z1 backgauge position in 21, and the calibrated zero BG frame is stored in PR 77.

Twist Adjust

M_SATWISTADJUST.LS

Twist Adjust macro applies the calculated twist offset to the tool frame to correct the sheet’s orientation. It is called after the Frame Set macro during dual backgauge alignment. If the sheet contacts Z1 first, the macro applies a Z- twist; if it contacts Z2 first, it applies a Z+ twist. Both Tool Info and Get Shift TCP macros are called within this macro.

Arguments

AR[1,2,3,4] values are:
1 = UFrameNum → Machine, [This is a User Frame number. The machine frame is stored in this frame number.]
2 = UToolNum → Current tool, [This is a Tool Frame number. It determines which tool frame is currently active.]
3 = UFrameNum → New BGFrame, [This is a User Frame number. It determines in which frame number the new backgauge frame is stored.]
4 = UToolNum → New Shifted TCP [This is a Tool Frame number. It determines which tool frame will be used for the new shifted TCP.]

Call

CALL BGTWISTADJUST(1,3,12,11) ;

The arguments indicate: the machine frame is stored in UFrame 1, the current tool frame is UTool 3, the new backgauge frame is stored in UFrame 12, and the new shifted TCP will be stored in UTool 11.

Tool Info

M_TOOLINFO.LS

Tool info macro sends the current tool frame value to the PLC and also sends current TCP positon from the new backgauge frame to the PLC.

Get Shift TCP

M_GETSHIFT_TCP.LS

Get Shift TCP macro reads the new tool frame values calculated by the PLC. The PLC writes the calculated TCP shift values into Registers from R[81] to R[86]. Then writes these values into position register PR[73].

How TCP Shift Works

When the sheet approaches either Z1 or Z2 backgauge:

  1. Based on the backgauges values from the registers, the Sheet Alignment macro determines which backgauge is contacted first.

  2. Then, the PLC calculates a TCP shift that moves the tool center point from its original position to the center of the contacted backgauge flat.

  3. By relocating the TCP to the contacted side, the robot can twist the sheet in the opposite direction — correcting the angular misalignment.

  4. The robot then advances again, and the loop repeats until both sides are in contact.

The TCP is shifted toward the side that made contact first. If Z1 touches first, the TCP moves to flat 1’s center; if Z2 touches first, it moves to flat 2’s center.
Twist adjustment only applies when one side of the sheet is contacting the backgauge. If both sides make contact simultaneously, the TCP shift is zero and no twist correction is performed.
