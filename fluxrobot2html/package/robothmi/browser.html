Browser

The HMI FLUX ROBOT is the HMI for monitoring and controlling the Flux Robot cell.

Navigation Panel

The left side of the screen provides access to the following sections:

  • UTILITIES - Access utility functions and settings.

  • IO - View and monitor input/output signals.

  • HOMING - Execute robot homing routines.

  • REGISTER - View robot registers.

Backgauge Analog Values

Displays the current analog position values of the backgauge axes:

  • Z1 - Analog value for backgauge axis Z1.

  • Z2 - Analog value for backgauge axis Z2.

These values update in real time and are used to verify backgauge positioning.

Stack Height

  • Enter Stack Height - Input field to manually enter the height of the sheet stack (in mm).

  • Actual - Displays the currently measured stack height.

Frame Correction

The FRAME CORRECTION button directs the user to the frame correction page.

Fence Status

This indicator will reflect the open and close state of the fence.
