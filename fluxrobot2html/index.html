Welcome to FluxRobot

Welcome to FluxRobot

FluxRobot is a robotic bending automation system that integrates a robot arm, press brake, and associated hardware and software to perform automated bending operations.

This documentation is the complete reference guide for setting up and operating the FluxRobot system using FluxRobot CAM and Right-Angle software.

New here? Start with Safety Precautions, then follow the System Overview to understand the cell before configuring anything.
