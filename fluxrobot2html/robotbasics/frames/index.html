Frames

A frame is a reference coordinate system that defines the position and orientation of an object in the robot’s workspace. Frames translate one coordinate system into another, enabling the robot to move correctly relative to tools, workpieces, and external components. Each component in the cell can have its own coordinate system, and frames connect these coordinate systems so all parts work together accurately.

Types of Frames

1. Tool Frame

  • The Tool Frame defines the position and orientation of the Tool Center Point (TCP) relative to the robot’s wrist flange.

  • The TCP is a specific point in space that represents the tip of the tool. Without a Tool Frame, the robot only knows the position of its flange center, so the user needs to calibrate the TCP to teach the robot where the tool tip is located.

  • Setting the Tool Frame ensures the robot moves and rotates the tool accurately for tasks like picking, bending, depositing etc.

2. User Frame

A User Frame defines the coordinate system of an external component in the robot’s workspace. Each component such as the press brake, pickup pallet, centering table, or deposit has its own User Frame. The user can calibrate each frame individually and teach the robot where the component is located.

During operation, the robot program switches the active User Frame based on the current process step. This allows the robot to move and perform tasks accurately relative to the specific component it is interacting with.

3. Jog Frame

Used for manually jogging the robot, the Jog Frame allows the user to move the robot in a specific coordinate system. This is particularly useful for tasks like teaching or programming the robot manually. When the robot is in Jog Coordinate System, it will move according to the selected jog frame’s coordinate system, allowing for precise control during setup and adjustments.

Unlike the User Frame, the Jog Frame is used only for manual jogging and does not affect programmed robot motions. Jog Frames are useful for Teaching positions where the component axes do not align with the World or User coordinate system.

See the Frame Calibration for more details on how to calibrate the User or Tool Frame for each external component.
