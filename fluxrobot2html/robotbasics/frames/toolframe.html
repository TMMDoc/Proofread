Tool Frame

Tool Frame

  • The Tool Frame defines the position and orientation of the Tool Center Point (TCP) relative to the robot’s wrist flange.

  • The TCP is a specific point in space that represents the tip of the tool. Without a Tool Frame, the robot only knows the position of its flange center, so the user needs to calibrate the TCP to teach the robot where the tool tip is located.

  • Setting the Tool Frame ensures the robot moves and rotates the tool accurately for tasks like picking, bending, depositing etc.

Tool Frame Orientation

The below table shows the orientation of the Tool Frame for different tools used.

Pointed Tool

Y+ → Y-

Tool Frame 2

Combi Gripper (Vacuum)

X+ → X+
Y+ → Y+
Z+ → Z+

Combi gripper uses Vacuum suction for picking the part from the Pickup pallet to placing it on the Centering table.

Note: Combi gripper is a combination of jaw-type and vacuum suction gripper.

0, 0, 0

Tool Frame 3

Combi Gripper (Jaw)

X+ → Z+
Y+ → X+
Z+ → Y-

Combi’s jaw gripper takes the part from Centering table to perform the bending operation and deposition.

90, 0, 90

Tool Frame 4

Vacuum Gripper

X+ → X+
Y+ → Y+
Z+ → Z+

This gripper uses Vacuum suction for complete handling of the part from Pickup to deposition.

0, 0, 0
