Frame Calibration

Frame Calibration

Frame calibration is a critical step in robot setup that ensures the robot’s coordinate system is accurately aligned with the physical workspace and tooling. Proper calibration allows for precise and repeatable robot movements, which is essential for bending tasks.

Tool Frame (TCP) Calibration

Tool Frame calibration, also known as TCP (Tool Center Point) calibration, is the process of defining the exact position and orientation of the tool’s tip relative to the robot’s flange.

Pre-setup for TCP Calibration

  1. Mounting Plane: A fixed surface to hold the reference tool during calibration. In our setup, we used a stable table as the mounting plane surface.

  2. Reference Tool: A pointed-end tool mounted on the mounting plane. This tool helps define the exact tip of the tool (TCP). We used a pointed screwdriver for accuracy.(Using a sharp, well-defined tool is important for precise TCP calculation.)

Setup

  1. Before recording any TCP points, make sure the correct pre-setup is done — otherwise, the calibration will be incorrect.

  2. Set Tool Frame to Zero tool.

    1. Select a tool frame that has no offset values (all X, Y, Z, W, P, R = 0)

    2. This ensures the robot calculates the TCP from the robot flange, not from an existing offset.

      If you select a tool frame that already has values, the robot will calculate the new TCP relative to the old one, not from the base of the robot arm. For Example: In our robot, Tool Frame 9 is the zero tool (all values are zero).

    3. To set Tool frame as zero: Press SHIFT + COORD in TP, then select Tool and Press 9 to set the zero tool.

Methods for Setting TCP

FANUC supports additional methods for TCP setup. We have explored only the most commonly used ones above. Refer to the robot manual for other available methods.

Six-Point Method For Tool Frame

In six-point method, you will teach a total of six points to calculate the Tool Center Point (TCP).

This method calculates both the position and orientation of the tool.

The user can decide and set any direction as X and Y (or X and Z), based on how the tool is mounted. This makes it ideal for tools that are tilted, rotated, or mounted in unique orientations.
# Point Description Image Calibration Procedure

1

Three Approach Points

The robot needs to find exactly where your tool tip is in 3D space. To do this, you need to touch the same fixed reference point (e.g. the screwdriver tip on the table) three times — each time from a different angle. The three recorded positions allow the robot to triangulate the exact position of the TCP.

Important: The 3 approach points have to be coplanar and non collinear to ensure accurate TCP calculation. If the point are collinear, the TCP values X, Y, Z, W, P, R will be Zero.

  1. Slowly jog the robot until your tool tip touches the reference tip precisely.

  2. Press SHIFT + RECORD on the teach pendant to save this position.

  3. A confirmation message will appear — the point is now recorded.

  4. Move away from the reference tip.

  5. Change the robot’s wrist/arm angle clearly before approaching again — do not come from the same direction.

  6. Repeat steps 1–3 for Approach Point 2 and Approach Point 3.

  7. The robot will automatically calculate the TCP once all three points are recorded.

2

Orient Origin Point

It is a reference point for orientation. The orient origin helps define the tool’s base direction (Z-axis), and it must be perpendicular to the mounting plane.

Note: The tool tip should touch the mounting surface perpendicularly, which makes the tool’s Z-axis perpendicular to the surface.

  1. Touch the mounting surface perpendicularly using the tip of the tool, pointing straight down toward the mounting plane.

  2. Select Orient Origin Point and press SHIFT + RECORD on the TP to record the orient origin point.

3

X-Direction Point

It defines the direction of the tool’s X-axis. The user can choose any direction for X axis, depending on their application or preferred orientation.

  1. From the Orient Origin position, jog the robot in the desired X direction of the tool.

  2. Move a noticeable distance in that direction (at least 100 mm is recommended for accuracy).

  3. Select X direction point and press SHIFT + RECORD in TP to save this point.

4

Y-Direction Point

It defines the direction of the tool’s Y-axis. The user has to choose Y direction perpendicular to the X direction. The robot will automatically calculate the Z-axis.

  1. Return to the Orient Origin position (press SHIFT + MOVETO on the recorded origin point).

  2. Jog the robot in the Y direction perpendicular to the recorded X direction of the tool.

  3. Move a noticeable distance in that direction (at least 100 mm is recommended).

  4. Select Y direction point and press SHIFT + RECORD in TP to save this point.
Post TCP Setup for Six-Point Method

  1. After setting the TCP, set the Tool Frame to the correct tool number which was chosen to find TCP by pressing SHIFT + COORD in TP, then select the tool number.

  2. Then press COORD to switch to Tool.

  3. Jogging in the Tool Frame will now move the robot in the tool’s direction, and the displayed coordinates will match the tool’s orientation.

Three-Point Method For Tool Frame

In the three-point method, only three approach points are needed. The user cannot define the tool’s orientation manually, so the robot calculates the direction based on its existing coordinate system and assumes the tool is aligned with the default Z-axis.

User and Jog Frame Calibration

Three-Point Method For User & Jog Frame

The Three-Point Method allows you to define a custom coordinate system by teaching the following three points. The same procedure is used for both User Frame and Jog Frame.

# Point Description Image Calibration Procedure

1

Origin Point (Orient Origin)

This point defines the origin of the frame. It is the reference point to record the X and Y direction points. The robot will calculate the position of this point as (0, 0, 0) in the new frame.

Note: While calculating the all three poins, ensure the tool tip is perpendicular to the frame.

  1. Place the calibration tool tip precisely at the origin of the desired frame.

  2. Select Orient Origin Point and press SHIFT + RECORD on the TP to save this point.

2

X-Direction Point

It defines the direction of the tool’s X-axis. The user can choose any direction for X axis, depending on their application or preferred orientation.

  1. From the origin point, move the tool tip approximately 100 mm along the desired X direction.

  2. Select X direction point and press SHIFT + RECORD on the TP to record this point.

3

Y-Direction Point

It defines the direction of the tool’s Y-axis. The user has to choose Y direction perpendicular to the X direction. The robot will automatically calculate the Z-axis.

  1. Return to the origin point (press SHIFT + MOVETO on the recorded origin point).

  2. Move the tool tip approximately 100 mm along the desired Y direction.

  3. Select Y direction point and press SHIFT + RECORD on the TP to record this point.

Key Differences in Usage

  • User Frame: Affects all programmed motions. Use this when programming relative to a part, fixture, or table.

  • Jog Frame: Affects only manual jogging. Useful during setup or when jogging in a frame aligned to the tool or a different plane.

Jog Frame does not affect robot programs, while User Frame does.

Direct Entry of Frames

This method allows you to manually input the coordinate values for the Tool Frame or User Frame.

  • You can enter the origin position (X, Y, Z) and the orientation (W, P, R) directly into the frame.

  • Use this when the exact TCP position or user frame orientation is already known through CAD models, measurements, or prior calculations.

  • Access the frame setup menu, choose the desired Tool or User frame, and enter the values using the function keys and numeric/alphabet input.

  • Press ENTER to save the frame after all values are entered.

Ensure no unnecessary tool or user frame is active when performing direct entry to avoid compounding offsets. Use SHIFT + COORD to switch to the desired frame.

Example

  • The teach pendant allows direct input of TCP values when the design data already contains the tool offset.

  • For example, consider a cylindrical tool concentric with the robot flange and 100 mm in length along the Z-axis.

  • In this case, you can directly enter Z = 100 mm in the TCP direct entry screen, which shifts the TCP from the flange center to the tool tip.
